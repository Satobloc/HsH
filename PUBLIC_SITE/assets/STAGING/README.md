## Admission rule

A staged visual must be reviewed for:
- provenance / creator;
- historical vs current context;
- P / H / I visual class where applicable;
- scientific vs illustrative role;
- caption and alt text;
- crop/focal guidance;
- duplicate/near-duplicate status;
- public-safety/privacy;
- canonical archive location.

Only reviewed assets are promoted into `PUBLIC_SITE/ASSET_MANIFEST.json` or a public gallery.
