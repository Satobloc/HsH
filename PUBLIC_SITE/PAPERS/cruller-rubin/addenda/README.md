# Crullerverse addenda

Save a typeset PDF and a sibling metadata JSON here. Follow the templates and instructions in `PUBLIC_SITE/PAPERS/README.md`. Set `parent_id` to `cruller-rubin`, use sequence 1 for the first addendum, and set `published: true` only when ready for public display. The live reader places each published addendum directly after the main paper, then in ascending sequence order. This README does not create an addendum.
