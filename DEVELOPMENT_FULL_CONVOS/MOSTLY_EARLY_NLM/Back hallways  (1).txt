Back-Hallway Test Harness (concise plan)

0) Objects.
	•	Let P be SAT’s primitive parameter set (angles/overlaps/exponential ladder, etc.).
	•	Each big theory T_i (e.g., QFT, GR, Cosmology) has a projection \pi_i: P \to \mathcal{O}_i taking SAT primitives to that theory’s observables.

1) Define each hallway as a functorial map.
A “back hallway” from T_i to T_j is the composition
H_{i\to j} := \pi_j \circ \pi_i^{-1}
restricted to the shared domain where \pi_i is invertible (or pseudo-inverse if many-to-one). In words: infer SAT primitives from theory i and re-emit predictions in theory j.

2) Unit tests for a hallway H.
	•	Round-trip consistency: \pi_i \approx \pi_i \circ \pi_j^{-1} \circ \pi_j (noisy identity).
	•	Cross-prediction accuracy: Use data only from T_i to predict observables in T_j; score errors vs. current measurements.
	•	Sensitivity & degeneracy: Vary each SAT primitive; chart which T_j observables move (Jacobian, condition number).
	•	Robustness: Stress with uncertainty in T_i inputs; verify predictions in T_j remain within experimental tolerances.

3) Minimal hallway kit (repeat per pair).
	•	Inputs: A small, clean set of T_i observables (with uncertainties).
	•	Inversion: Solve/fit for \hat P (MAP or least-squares with priors that respect SAT structure).
	•	Forward map: Compute \pi_j(\hat P) and uncertainties (via linear error propagation or bootstrap).
	•	Metrics: χ² / log-likelihood against T_j data; round-trip residuals; Shapley/gradient attributions to see which SAT primitives carry the translation.
