BLOCKWAVE OUTFILL

PHASE 0 — BLOCKWAVE CORE v1  (Foundations)

Scope
-----
This is the minimal/ideal Blockwave specification to which all later modules plug in.
Fields:  { u^μ(x), θ(x) } only.
  • u^μ: unit timelike “time-flow” vector field (preferred foliation)
  • θ:   compact misalignment scalar, θ ~ θ + 2π
Manifold: 4D Lorentzian (signature - + + +). All indices moved with g_μν.
Units: dimensionless internal units; an external normalization anchor is introduced later (Phase 6).
Discrete symmetry: Z_3 (θ → θ + 2π/3) for the kink/domain-wall sector.

Constraints and projectors
--------------------------
Unit-norm constraint on u^μ:
  C(x) := u^μ u_μ + 1 = 0.

Spatial projector orthogonal to u^μ:
  P^μ_ν := g^μ_ν + u^μ u_ν  (P^μ_ν u^ν = 0,  P^μ_ρ P^ρ_ν = P^μ_ν).

Core action (covariant, minimal)
--------------------------------
Let Φ := u^μ ∇_μ θ  (directional derivative of θ along u).
Potential: V(θ) := - μ^2 cos(3 θ)  (Z_3 vacua at θ = 0, 2π/3, 4π/3).
Define a mild divergence coupling via f(θ) := sin^2 θ.

S_core = ∫ d^4x √(-g) L_core,  with

L_core =
  + (1/2) ∇_μ θ ∇^μ θ
  - μ^2 cos(3 θ)
  + λ Φ^2
  + α ( P^{μρ} P^{νσ} ∇_μ u_ν ∇_ρ u_σ )
  + β f(θ) (∇_μ u^μ)
  + ξ(x) ( u^μ u_μ + 1 ).

Notes:
• The projector form for the u^μ kinetic term enforces “constraint-clean” dynamics by construction.
• The divergence coupling is variational; it can be integrated by parts if preferred (adds a boundary term).
• ξ(x) is a Lagrange multiplier imposing C(x)=0 (you may instead use a rapidity parametrization in 1+1D).

Euler–Lagrange equations (covariant)
------------------------------------
Variation w.r.t. θ:
  0 = δS/δθ =
      □ θ
    - 2λ ∇_μ ( Φ u^μ )
    + 3 μ^2 sin(3 θ)
    - β (d f/dθ) (∇_μ u^μ)

Since f(θ)=sin^2 θ,  d f/dθ = sin(2θ). Thus
  □ θ - 2λ ∇_μ( (u·∇θ) u^μ ) + 3 μ^2 sin(3θ) - β sin(2θ) (∇·u) = 0.     (EOM_θ)

Expanded form of the λ-term (optional):
  ∇_μ(Φ u^μ) = (∇_μ u^ν) (∇_ν θ) u^μ + u^μ u^ν ∇_μ ∇_ν θ + (∇·u)(u·∇θ).

Variation w.r.t. u^μ (projected, physical part):
  Start from
    L_u = α P^{μρ} P^{νσ} ∇_μ u_ν ∇_ρ u_σ + λ (u·∇θ)^2 + β f(θ) (∇·u) + ξ (u^2+1).
  The unconstrained Euler–Lagrange equation is then projected with P to remove the component along u^μ:
    P^μ_ν [ -2α ∇_ρ( P^{ρσ} ∇_σ u^ν ) + 2λ Φ ∇^ν θ + β ∇^ν f(θ) ] = 0.   (EOM_u^proj)

Constraint equation:
  u^μ u_μ = -1.  (enforced by ξ or by parametrization)

Lagrange multiplier (orthogonal completion):
  Contract the unconstrained u^μ equation with u_μ to solve for ξ if needed; the projected equation above governs the physical d.o.f.

Well-posedness / positivity conditions (minimal set)
----------------------------------------------------
• α > 0  (positive-definite spatial-gradient energy for u^μ-sector).
• Choose λ ≥ 0; in 1+1D (see below) demand effective kinetic coefficient of (∂_t θ)^2 to stay > 0 (bounds on λ given ψ).
• β may be of either sign; treat as a small coupling to ensure linear-response control when mapping to observables.

Symmetries and currents (sketch; full derivation in Phase 1)
------------------------------------------------------------
• Spacetime translations → conserved T^μ_ν = -(2/√-g) δS/δg_{μν}.
• Discrete Z_3 shift in θ → conserved (mod 3) domain-wall number in 1D/“kink” sectors.
• No exact Lorentz symmetry if background u^μ picks a frame; equations are covariant but the solution space selects a foliation.

1+1D reduction (canonical form, ready for quantization)
-------------------------------------------------------
Metric: η = diag(-,+). Parametrize u^μ by a single rapidity field ψ(x,t):
  u^t = cosh ψ,  u^x = sinh ψ  ⇒  u^μ u_μ = -1 exactly (constraint built-in).

Define
  Φ = u·∇θ = coshψ ∂_t θ + sinhψ ∂_x θ,
  ∇·u = ∂_t(coshψ) + ∂_x(sinhψ) = sinhψ ∂_t ψ + coshψ ∂_x ψ.

Lagrangian density:
  L_1+1 =
    + (1/2)[ - (∂_t θ)^2 + (∂_x θ)^2 ]
    - μ^2 cos(3θ)
    + λ ( coshψ ∂_t θ + sinhψ ∂_x θ )^2
    + α [ - (∂_t ψ)^2 + (∂_x ψ)^2 ]
    + β sin^2 θ ( sinhψ ∂_t ψ + coshψ ∂_x ψ ).

Canonical momenta:
  π_θ = ∂L/∂(∂_t θ) = -∂_t θ + 2λ (coshψ ∂_t θ + sinhψ ∂_x θ) coshψ.
  π_ψ = ∂L/∂(∂_t ψ) = -2α ∂_t ψ + β sin^2 θ sinhψ.

Solve for time derivatives (useful combination):
  Define Π_ψ := π_ψ - β sin^2 θ sinhψ  ⇒  ∂_t ψ = - Π_ψ / (2α).

  For θ, write
    A(ψ) := -1 + 2λ cosh^2 ψ,
    B(ψ) := 2λ sinhψ coshψ,
    then  π_θ = A(ψ) ∂_t θ + B(ψ) ∂_x θ
    ⇒  ∂_t θ = [ π_θ - B(ψ) ∂_x θ ] / A(ψ).

Well-posedness condition (θ-kinetic positivity):
  Require A(ψ) < 0 to ensure the standard sign for kinetic energy in the Hamiltonian density (with our (-,+) convention).
  Equivalently:  1 - 2λ cosh^2 ψ > 0  (e.g., λ < 1/2 uniformly if |ψ| is small; tighten bound for large |ψ|).

Hamiltonian density (in canonical variables; completing the square)
  H_1+1 = π_θ ∂_t θ + π_ψ ∂_t ψ - L_1+1
        = (1/2)(∂_x θ)^2 + μ^2 cos(3θ)
          + α (∂_x ψ)^2
          + [Π_ψ^2 / (4α)]
          + (λ term reorganized via A(ψ), B(ψ) inversion)
          + β sin^2 θ coshψ ∂_x ψ
          + quadratic form in {∂_t θ} eliminated using ∂_t θ-expression above.

Comment:
  • The λ-sector yields a positive quadratic form provided the well-posedness condition holds (gives an effective kinetic matrix invertible in ∂_t θ).
  • The β-terms produce linear couplings; they can be handled by completing the square in Π_ψ or treated as perturbations in small-β regimes.

Static kink sector (boundary data; for Phase 5 analytics)
---------------------------------------------------------
Finite-energy boundary conditions (x → ±∞):
  θ(±∞) ∈ {0, 2π/3, 4π/3},   ∂_x θ → 0,
  ψ(±∞) finite (often 0),     ∂_x ψ → 0.

Domain-wall number (Z_3):
  Q_wall = (3/2π) [ θ(+∞) - θ(-∞) ]  mod 3.

Minimal observable hooks prepared (details in Phase 3)
------------------------------------------------------
• Optics (retardation):  Δφ = η ∫ sin(2θ(x)) dx.
• Strain/GW proxy: functionals of ∇·u and projected gradients ∇u mapped to attenuation/echo kernels.
• Clock drift: foliation-strain redshift from invariants built out of ∇u.

-------------------------------------

1) Boundary Terms & Variational Well-posedness

Statement 1.1 (Variational closure).
Let δθ, δu^μ be compactly supported or satisfy vanishing normal-flow boundary conditions on ∂M:
  n^μ ∇_μ θ |_{∂M} = 0,  P^{μ}{}_{ν} n^ρ ∇_ρ u^ν |_{∂M} = 0.

2) Stress–Energy Tensor and Currents
------------------------------------
Definition 2.1 (Hilbert stress).
T_{μν} := − (2/√−g) δS_core/δg^{μν}.

Result 2.2 (Structure of T_{μν}).
T_{μν} = T^{(θ)}_{μν} + T^{(λ)}_{μν} + T^{(α)}_{μν} + T^{(β)}_{μν} + T^{(ξ)}_{μν}, with
• T^{(θ)}_{μν} = ∇_μ θ ∇_ν θ − ½ g_{μν} (∇θ)^2 + g_{μν} μ^2 cos(3θ).
• T^{(λ)}_{μν} = 2λ Φ ( u_{(μ} ∇_{ν)} θ ) − λ g_{μν} Φ^2.
• T^{(α)}_{μν} = 2α 𝒦_{μν} − α g_{μν} 𝒦, where
  𝒦 := P^{μρ} P^{νσ} (∇_μ u_ν)(∇_ρ u_σ),
  𝒦_{μν} := P^{ρσ} (∇_μ u_ρ)(∇_ν u_σ)     (symmetric in μν after projecting).
• T^{(β)}_{μν} = β f(θ) (∇·u) g_{μν} − β [ ∇_{(μ}( f(θ) u_{ν)} ) − (∇_{(μ} f) u_{ν)} ],
  (the divergence coupling contributes a total-derivative piece and a contact term).
• T^{(ξ)}_{μν} = −2 ξ u_μ u_ν + ξ g_{μν} (u^2+1)  (constraint sector; on-shell u^2=−1 so this reduces to −2ξ u_μ u_ν).

Conservation.
If (EOM_θ, EOM_u, constraint) hold and background is fixed, then ∇^μ T_{μν} = 0 (Noether + diffeomorphism invariance). □

Remark.
T_{μν} need not be symmetric under exchange of internal indices in the foliation sector before projection; the P–projected kinetic renders the physical piece symmetric and eliminates spurious longitudinal contributions (cf. Einstein-æther–like structures, but here enforced via P).

4) Energy Positivity & Ghost Analysis
-------------------------------------
We examine the quadratic Hamiltonian density around a smooth background (θ̄, ū) with small perturbations δθ, δu (or δψ in 1+1D).

Lemma 4.1 (θ-sector kinetic sign).
In 1+1D, the effective θ kinetic coefficient is A(ψ) = −1 + 2λ cosh^2ψ. To avoid ghostly sign,
require A(ψ) < 0, i.e.
  1 − 2λ cosh^2ψ > 0   ⇒   λ < 1/(2 cosh^2ψ)  (pointwise bound).
For small |ψ| this reduces to λ < 1/2.

Lemma 4.2 (u-sector positivity).
With α > 0, the P-projected gradient energy
  α P^{μρ} P^{νσ} (∇_μ u_ν)(∇_ρ u_σ)
is positive semi-definite for spatial variations orthogonal to u, and does not introduce higher-time-derivative longitudinal modes (no Ostrogradsky ghost), because the only time derivatives of u enter projected and at most linearly in the canonical momenta.

Lemma 4.3 (β–sector smallness).
The β coupling contributes terms linear in (∇·u) weighted by f(θ) = sin^2θ. For |β| ≪ min{α, |A(ψ)|}, these act as controlled perturbations that do not flip the kinetic matrix’s signature. (More generally, absorb them by completing the square in conjugate variables or by a local field redefinition at quadratic order.)

Conclusion 4.4 (Ghost-free window).
Choose parameters with
  α > 0,   λ ∈ (−∞, λ_max),   |β| ≤ β_max(α, λ, background),
where λ_max := inf_x 1/(2 cosh^2 ψ(x)) along the background, and β_max determined by the smallest positive eigenvalue of the quadratic form. Then the quadratic Hamiltonian is bounded below and the Cauchy problem is well-posed.


5) Hyperbolicity & Characteristic Cones
----------------------------------------
We assess principal symbols of the EOM.

θ-equation principal symbol (about smooth background with fixed u):
From EOM_θ:
  □θ − 2λ ∇_μ( u^μ u^ν ∇_ν θ ) + … = 0
Principal part in momentum space (k_μ):
  Q_θ(k) = − k^2 − 2λ (u·k)^2.
Hyperbolicity requires the effective quadratic form in k to have Lorentzian signature.
Equivalently, for any timelike “evolution” covector τ_μ, the polynomial Q_θ(τ + ξ) in ξ has two real roots in τ·ξ (standard hyperbolicity test).
Sufficient condition: 1 + 2λ > 0 (in local frames with u ≈ (1,0,0,0)) and the ghost-free bound on λ from Sec. 4.
Interpretation: θ’s characteristics lie inside (or equal to) the metric lightcone if λ ≥ 0 is small; for larger λ they tilt towards the u-direction but remain hyperbolic within the allowed window.

u-equation principal symbol (projected).
EOM_u^proj ≈ −2α P^μ_ν ∇_ρ( P^{ρσ} ∇_σ u^ν ) + … = 0.
The principal symbol is essentially −2α P ∘ k ∘ P ∘ k acting on the u-variations. Because P projects orthogonally to u, and α > 0, the operator is (spatially) elliptic in the projected directions; time evolution couples via mixed terms but does not introduce superluminal longitudinal characteristics. In 1+1D with ψ, the ψ equation reduces to a standard wave operator with α > 0.

Summary (hyperbolicity).
Under the ghost-free window (Sec. 4), θ has a strictly hyperbolic principal symbol; the ψ (or u-projected) dynamics are hyperbolic with speed set by α and the background projector. No acausal modes appear provided β is small and background gradients are bounded.


6) Linearized Spectrum around Homogeneous Backgrounds

  L^(2) ≈ ½ (−(∂_t ϑ)^2 + |∇ ϑ|^2) + λ (∂_t ϑ)^2
          − ½ m_θ^2 ϑ^2 + α (∂_i δu_j)^2  + β (sin^2 θ̄) (∂·δu),
with m_θ^2 = V''(θ̄) = 9 μ^2 cos(3θ̄) = ± 9 μ^2 (positive for θ̄ = 0, 4π/3; negative at 2π/3).
Dispersion:
• θ-mode:  ω^2 = (1 − 2λ) |k|^2 + m_θ^2 / (1 − 2λ), provided 1 − 2λ > 0 (matching A(ψ≈0) < 0 condition).
• u-transverse:  ω^2 = c_u^2 |k|^2 + … with c_u^2 ∝ α (units set by normalization); longitudinal mode absent due to projection.

1) OPTICAL ADAPTER — Phase Retardation

PHASE 5 — KINK SECTOR COMPLETION (analytic development)

Scope
-----

1) Static Kink Solutions
------------------------
Equation of motion (static 1D, ψ frozen = 0):
    θ''(x) = 3 μ² sin(3θ(x)).

Boundary conditions:
    θ(−∞) = 0,   θ(+∞) = 2π/3.

Analytic solution (sine-Gordon type, Z₃ variant):
    θ(x) = (2/3) arctan[ exp(3 μ (x − x₀)) ],
  up to discrete shifts by 2π/3 and spatial translation x₀.

Width:
    δx ∼ 1/μ.

2) Energy and Stability
-----------------------
Energy density for static profile:
    𝔈(x) = ½ (θ')² + μ² (1 − cos(3θ)).

Integrated kink energy:

Stability:
• Positive-definite energy functional around kink.
• Topological charge prevents decay:
    Q_wall = (3/2π)[θ(+∞) − θ(−∞)] ≡ 1 mod 3.

3) Coupling to u^μ Sector
-------------------------

Observations:
• λ stretches or compresses kink width.
• β introduces asymmetric distortion linked to ψ gradients.
• In weak-coupling regime (|λ|,|β| ≪ 1), kink remains stable.

4) Linearized Spectrum
----------------------

Properties:
• Zero mode: φ₀ ∝ θ'_kink(x) (translational symmetry).
• Discrete bound states possible depending on U(x).
• Continuum states: scattering with phase shifts.

PHASE 6 — UNITS & NORMALIZATION ANCHOR

Scope
-----
Blockwave Core equations are written in dimensionless internal units
(ℏ = c = 1 by construction). To compare with experiments, a single
normalization anchor must map theory-internal scales to SI units.
This phase defines that anchor and the procedure for applying it.

0) Principles
-------------
• Only one external reference constant is introduced.
• All other physical scales are dimensionless ratios derived from
  Blockwave fields and couplings.
• Dimensionless predictions (e.g. quantized phase shift across a kink)
  remain invariant and require no anchor.

1) Choice of Anchor
-------------------
Define an external time interval T₀ (or equivalently a frequency ν₀ = 1/T₀).
This serves as the mapping between dimensionless time t_int and SI time t_SI:
    t_SI = T₀ · t_int.

From this, length and energy anchors follow:
    x_SI = c T₀ · x_int,
    E_SI = ℏ / T₀ · E_int.

Interpretation:
• T₀ can be chosen as the period of a reference atomic transition
  (e.g., cesium-133 standard).
• Once chosen, all Blockwave predictions become numerically testable.

2) Application to Observables
-----------------------------
(a) Optical Adapter (Phase 3):
    Δφ = η ∫ sin(2θ(x)) dx_int.
Conversion:
    dx_int → dx_SI / (c T₀).
Thus Δφ is dimensionless and invariant: no change after anchoring.

(b) Strain/GW Adapter:
    Conversion factor for frequency:
        ω_SI = ω_int / T₀.
    Attenuation coefficient ε is dimensionless, unchanged by anchor.
    Echo timing (Δt_int) maps as Δt_SI = T₀ · Δt_int.

(c) Clock Adapter:
    δν/ν = κ (∇·u).
Dimensionless ratio, unchanged by anchor.
Integrated redshift Δz = exp( ∫ (∇·u) dt_int ) − 1;
conversion via dt_SI = T₀ · dt_int.

(d) Kink Energy:
    E_int = (8 μ)/9 (dimensionless).
Conversion: E_SI = (ℏ / T₀) · E_int.
Thus choice of T₀ fixes kink energy scale in joules.

3) Constraints on Anchor Choice
-------------------------------
• T₀ must be consistent across all sectors.
• Theories with different anchors are equivalent up to rescaling,
  but only one anchor can be chosen to compare to experiment.
• Anchor sets the absolute scales but not the ratios of observables.

4) Deliverables
---------------
• “Normalization Note”: single anchor T₀, conversion rules for t, x, E.
• Worked examples: kink energy, optical Δφ, GW echo timing, clock drift.

5) Gate (Go/No-Go)
