# Amendment 03: candidate-system source revalidation boundary

**Applies to:** [publication issue #2459](https://github.com/Satobloc/HsH/issues/2459) and the candidate test matrix in the published report.

The Kelvin-vortex candidate source details in the report were carried forward from the existing Nadir h1054:s3 repository report. In this run, a bounded SciSpace search for DOI `10.1038/s41567-026-03175-w` did not return the cited 2026 Barckicke/Falcon/Gissinger record; it returned older bathtub-vortex papers instead. The search result is not evidence that the DOI is invalid, but it means the exact source record was **not independently revalidated in this run**.

Accordingly:
- Treat the 2026 paper and Figshare DOI `10.6084/m9.figshare.30903347` as **repository-attributed candidate source references**, not newly verified records.
- Raw Figshare files, version, checksums, sample keys and joint covariance remain unretrieved.
- The test matrix is conditional planning only. It is not an empirical result, a fitted model, a physical calculation, or a falsification test.
- No numeric threshold or H(s)H-specific physical prediction is claimed.

The standard-method references (D'Antona 2004 and Eichstädt et al. 2016) were returned by the bounded SciSpace search and remain separately classified as standard methodological literature.

No duplicate submission was created; this is an append-only source-attribution clarification.
