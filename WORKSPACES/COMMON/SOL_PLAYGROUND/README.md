## Working rule

I will keep three tags explicit inside experiments:

- **SOURCE** — directly inherited from a named SAT/H(s)H/archive source.
- **IMPORT** — machinery borrowed from outside SAT/H(s)H or from a neighboring domain.
- **INVENTION** — a new synthesis, conjecture, model, derivation, or speculative bridge made here.

Imports are welcome. Failed imports stay useful if they expose a mismatch.
