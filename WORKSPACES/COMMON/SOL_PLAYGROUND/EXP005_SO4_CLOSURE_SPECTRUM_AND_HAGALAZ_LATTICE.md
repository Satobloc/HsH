## 1. Constant-generator laboratory

Take a closed carrier with tangent

\[
T(s)=Q(s)T_0,
\qquad
Q_s=Q\Omega_0,
\qquad
\Omega_0\in\mathfrak{so}(4)
\]

and constant generator \(\Omega_0\).

Any real antisymmetric \(4\times4\) matrix can be brought by an orthogonal change of basis to two commuting planar rotation blocks. Write

\[
\Omega_0=\omega_1J_{12}+\omega_2J_{34}.
\]

Let the unit initial tangent have nonzero projections into both planes. After a basis choice,

\[
T(s)=
\big(
 a\cos\omega_1s,
 a\sin\omega_1s,
 b\cos\omega_2s,
 b\sin\omega_2s
\big),
\qquad a^2+b^2=1.
\tag{1}
\]

This is automatically unit speed.

Integrating once gives

\[
X(s)-X(0)=
\left(
\frac{a}{\omega_1}\sin\omega_1s,
\frac{a}{\omega_1}(1-\cos\omega_1s),
\frac{b}{\omega_2}\sin\omega_2s,
\frac{b}{\omega_2}(1-\cos\omega_2s)
\right).
\tag{2}
\]

## 2. Exact positional closure

For \(a,b\neq0\), positional closure at length \(L\) requires

\[
\omega_1L=2\pi m,
\qquad
\omega_2L=2\pi n,
\qquad
m,n\in\mathbb Z.
\tag{3}
\]

Therefore

\[
\boxed{
\frac{\omega_1}{\omega_2}=\frac{m}{n}.
}
\tag{4}
\]

So the simplest nontrivial closed 4D double-rotation carriers already live on an integer mode lattice.

No particle label, magic angle, or fitted constant has been used.

The full frame holonomy is

\[
U(L)=e^{L\Omega_0}.
\]

For strict frame closure in \(SO(4)\), Eq. (3) gives

\[
U(L)=I.
\]

More general allowed holonomy classes can later weaken this condition, but strict closure is enough to expose the lattice.

## 3. Geometric invariants of the closed mode pair

From (1),

\[
X_{ss}=T_s
=
\big(
-a\omega_1\sin\omega_1s,
 a\omega_1\cos\omega_1s,
-b\omega_2\sin\omega_2s,
 b\omega_2\cos\omega_2s
\big).
\]

Hence the curvature magnitude is constant:

\[
\boxed{
\kappa^2
=a^2\omega_1^2+b^2\omega_2^2.
}
\tag{5}
\]

Using closure,

\[
\boxed{
\kappa^2
=\left(\frac{2\pi}{L}\right)^2
M_2,
\qquad
M_2:=a^2m^2+b^2n^2.
}
\tag{6}
\]

The next derivative gives

\[
|X_{sss}|^2
=a^2\omega_1^4+b^2\omega_2^4
=\left(\frac{2\pi}{L}\right)^4M_4,
\tag{7}
\]

with

\[
M_4:=a^2m^4+b^2n^4.
\]

Thus the integer pair \((m,n)\) controls a hierarchy of geometric moments.

## 4. A discrete stationary length spectrum

Take a static effective energy containing line/core energy, bending, and a higher-gradient geometric penalty:

\[
E
=\sigma L
+\frac B2\int_0^L\kappa^2ds
+\frac D2\int_0^L|X_{sss}|^2ds.
\tag{8}
\]

Because the invariants are constant,

\[
\boxed{
E_{m,n}(L)
=
\sigma L
+\frac{2\pi^2B}{L}M_2
+\frac{8\pi^4D}{L^3}M_4.
}
\tag{9}
\]

Stationarity with respect to \(L\) gives

\[
\sigma
-\frac{2\pi^2BM_2}{L^2}
-\frac{24\pi^4DM_4}{L^4}
=0.
\tag{10}
\]

Let \(y=L^2\). Then

\[
\sigma y^2-2\pi^2BM_2y-24\pi^4DM_4=0.
\]

The positive branch is

\[
\boxed{
L_{m,n}^2
=
\frac{\pi^2}{\sigma}
\left[
BM_2+
\sqrt{B^2M_2^2+24\sigma DM_4}
\right].
}
\tag{11}
\]

This is a genuine discrete stationary length spectrum generated by:

1. continuous geometry;
2. positional/frame closure;
3. ordinary elastic coefficients.

No discrete particle spectrum was inserted.

If \(D\to0\),

\[
\boxed{
L_{m,n}^2
\to
\frac{2\pi^2B}{\sigma}M_2.
}
\tag{12}
\]

Substituting back gives

\[
E^*_{m,n}
=2\sqrt{2\pi^2\sigma B M_2}
\]

for the \(D=0\) model.

So the energy levels scale as

\[
\boxed{
E^*_{m,n}\propto\sqrt{a^2m^2+b^2n^2}.
}
\tag{13}
\]

This is not claimed to be the observed mass spectrum. It is proof-of-principle that a discrete spectrum can emerge from H(s)H closure plus elasticity with no target numbers.

## 6. The SO(4) self-dual / anti-self-dual split

Introduce normalized self-dual and anti-self-dual generators

\[
\Sigma_+=\frac{J_{12}+J_{34}}{\sqrt2},
\qquad
\Sigma_-=\frac{J_{12}-J_{34}}{\sqrt2}.
\]

Then

\[
\Omega_0
=
\frac{\omega_1+\omega_2}{\sqrt2}\Sigma_+
+
\frac{\omega_1-\omega_2}{\sqrt2}\Sigma_-.
\tag{15}
\]

Using closure,

\[
\omega_1=\frac{2\pi m}{L},
\qquad
\omega_2=\frac{2\pi n}{L},
\]

so define

\[
p=m+n,
\qquad
q=m-n.
\tag{16}
\]

Then the two Cartan-sector amplitudes are proportional to

\[
\boxed{
p\quad\text{and}\quad q.
}
\tag{17}
\]

Since

\[
\mathfrak{so}(4)
\cong
\mathfrak{su}(2)_+\oplus\mathfrak{su}(2)_-,
\]

the full six rotational degrees of freedom separate into two triplets, while this constant-generator solution samples one direction in each triplet.

Important arithmetic restriction:

\[
p\equiv q\pmod 2,
\]

because \(m=(p+q)/2\), \(n=(p-q)/2\) must be integers.

This is the first nontrivial discrete constraint that appears when the 3+3 algebraic split is combined with closure.

A generalized quadratic frame energy

\[
E_{\rm frame}
\sim
C_+\|\Omega_+\|^2
+C_-\|\Omega_-\|^2
\]

therefore yields a closed-sector spectrum controlled by

\[
\boxed{
C_+p^2+C_-q^2
}
\]

up to common normalization factors.

Again: this does not prove that the project's independent 3+3 construction is this split. It gives a concrete testable candidate.

## 7. Strong constraint on recursive ᚼ

Now assume ᚼ maps one closed constant-generator state to another while preserving the same period \(L\).

Represent the closed state by its mode vector

\[
k=
\begin{pmatrix}m\\n\end{pmatrix}
\in\mathbb Z^2.
\]

Suppose the linearized recursion acts as

\[
k' = A k.
\tag{18}
\]

If **every** closed integer mode must map to another closed integer mode, then

\[
A\mathbb Z^2\subseteq\mathbb Z^2.
\]

Therefore

\[
\boxed{A\in M_2(\mathbb Z).}
\tag{19}
\]

If the recursion is invertible on the closed-mode lattice,

\[
\boxed{A\in GL(2,\mathbb Z).}
\tag{20}
\]

If it additionally preserves orientation and primitive lattice area,

\[
\boxed{A\in SL(2,\mathbb Z).}
\tag{21}
\]

This is a major constraint:

> A closure-preserving linear ᚼ recursion on the double-rotation sector cannot be an arbitrary real matrix. It must act by an integer lattice automorphism.

That makes the recursion **modular/arithmetic** rather than freely tunable.

## 8. Recursive scaling can emerge from the ᚼ lattice map

Iterating ᚼ gives

\[
k_N=A^Nk_0.
\tag{22}
\]

The qualitative recursive behavior is then classified by the eigenvalues of \(A\).

### Elliptic / finite-order

If the eigenvalues lie on the unit circle and \(A\) has finite order, the mode sequence is periodic.

### Parabolic

If \(|\operatorname{tr}A|=2\) with a repeated unit eigenvalue, mode growth is polynomial/linear.

### Hyperbolic

If

\[
|\operatorname{tr}A|>2,
\]

then for \(A\in SL(2,\mathbb Z)\) the eigenvalues are

\[
\lambda_\pm
=
\frac{\operatorname{tr}A\pm\sqrt{(\operatorname{tr}A)^2-4}}{2},
\qquad
\lambda_+\lambda_-=1.
\tag{23}
\]

Repeated recursion produces asymptotic scaling

\[
\boxed{
\|k_N\|\sim |\lambda_+|^N.
}
\tag{24}
\]

So an exponential recursive scale hierarchy can emerge from an integer closure-preserving operator rather than an inserted real scale factor.

Example only, not privileged:

\[
A=
\begin{pmatrix}
2&1\\
1&1
\end{pmatrix}
\in SL(2,\mathbb Z)
\]

has

\[
\lambda_+=\frac{3+\sqrt5}{2},
\qquad
\lambda_-=\frac{3-\sqrt5}{2}.
\]

The point is not the golden ratio. The point is that **algebraic scaling ratios are forced once a specific integer ᚼ map is derived**.
