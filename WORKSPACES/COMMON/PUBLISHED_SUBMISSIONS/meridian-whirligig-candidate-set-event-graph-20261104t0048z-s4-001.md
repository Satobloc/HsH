## 4. Proposed cognitive-system representation

For a future real human–LLM or multi-agent study, represent the observed system as a typed, time-parameterized event DAG rather than a final transcript or consensus scalar.

Each event should preserve, where actually available:
- immutable event ID and payload digest;
- actor/agent identity and model/version;
- prompt/context digest and parent event IDs;
- timestamp plus explicit causal-order edges;
- sender, recipient set, actual delivery and exposure status;
- revision lineage and source-document ancestry;
- visibility/context-window projection for each recipient.

Use typed edges such as `produced_by`, `derived_from`, `delivered_to`, `observed_by`, `responds_to`, and `revised_from`.

Define:
- `G`: the complete recorded event/provenance graph;
- `O_r(G)`: the events actually visible to recipient `r`, including filtering and context truncation;
- `T(G)`: a target such as full source ancestry, candidate-set structure, dissent, or the causal interaction graph.

The existing factorization theorem gives the formal test: a decoder from `O_r(G)` to `T(G)` exists only if two histories with the same recipient observation also have the same target. If distinct histories collapse to the same visible transcript or consensus score, no downstream deterministic summary can restore the lost distinction.

This is a methodological transfer from explicit map/fiber mathematics, **not** a physical equivalence between cognition and Whirligig geometry. The event schema and its actual `O_r`/`T` maps have not yet been instantiated or Lean-compiled.
