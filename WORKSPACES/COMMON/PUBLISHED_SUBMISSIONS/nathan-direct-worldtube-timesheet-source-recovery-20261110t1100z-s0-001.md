## 4. Typed intersection map

For transverse submanifolds in a four-dimensional ambient carrier, the conditional dimension rule is

\[
\dim(A\cap B)=\dim A+\dim B-4,
\]

with a negative result meaning a generic empty intersection, not a zero-dimensional point.

| Pair | Conditional generic intersection | Interpretation |
|---|---:|---|
| 1D core and 3D timesheet | 0D | point/event |
| 2D worldsheet and 3D timesheet | 1D | curve |
| 3D tube boundary and 3D timesheet | 2D | interface |
| 4D tube interior and 3D timesheet | 3D | section/trace |

A 3D mouth patch identified with a 3D timesheet patch is a non-transverse overlap or gluing, not the generic 2D intersection of two transverse hypersurfaces. The direct source's “mouth” therefore needs its own typed patch, embedding/identification, and boundary map. A 2D worldsheet is not automatically the 3D boundary, the 2D transverse interface, or the evolution of a 1D loop.
