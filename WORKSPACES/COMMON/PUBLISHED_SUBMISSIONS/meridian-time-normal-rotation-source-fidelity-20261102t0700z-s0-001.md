## 5. The geometry fork

The archive currently mixes four distinct possibilities:

1. **Hypersurface-normal bending:** if \(u=n\) is the unit normal to a smooth codimension-one hypersurface \(\Sigma_t\), its tangential derivative defines the shape operator/second fundamental form \(K_{ij}\). The normal direction can turn through the Gauss map. The normal bundle is one-dimensional, so there is no independent internal \(SO(2)\) normal-plane rotation for a codimension-one hypersurface.
2. **Congruence vorticity:** if \(u\) is a non-integrable vector-field congruence, its projected antisymmetric derivative can be nonzero. But then \(u\) is not the normal to a global foliation. If it is hypersurface-orthogonal, the Frobenius condition forces projected vorticity to vanish.
3. **Cartan torsion:** this belongs to an independently specified affine connection, \(T^\rho{}_{\mu\nu}=2\Gamma^\rho{}_{[\mu\nu]}\). It is not the same as congruence vorticity or hypersurface extrinsic curvature.
4. **Path-dependent holonomy:** this requires a connection one-form and a transport rule, \(U_\gamma=\mathcal P\exp\int_\gamma\Omega\), with curvature \(\mathcal R=d\Omega+\Omega\wedge\Omega\). A scalar norm \(\|D_s n\|\) is insufficient.

The 2025 SAT.4D glossary chooses \(u\) normal to \(\Sigma_t\). The 2025 compiled vorticity proposal simultaneously discusses a vorticity coupling while describing \(u\) as defining a foliation. Those assumptions conflict if the foliation is genuine. The 2026 direct description of the time surface as an interacting three-dimensional bulk may represent a later change, but it does not yet state whether the bulk is an integrable hypersurface family or a non-integrable distribution.

The 2026 native ++++ and literal \(cw=t\) convention also cannot be silently merged with the older Lorentzian Blockwave constraint \(u^2=-1\) or the earlier \(w=ct\) length-coordinate control. The prior TII/θ4 frame-boundary record already preserves this unresolved convention change. Forest Normalization remains unverified: the current working draft’s \(B=3/(4\pi)\) candidate retains an unproved factor of two, and the original “The Trees Themselves” source was not recovered.
