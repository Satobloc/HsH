## Executive result

The direct sources distinguish three questions that must not be collapsed:

1. **Carrier role:** where a perturbation may be supported or propagated (worldtube, timesheet, responsive medium).
2. **Representation status:** whether the medium replaces the timesheet, is represented as an elaboration of it, or is retained as an independent third primitive only if evidence and prior geometry require it.
3. **Response activity:** whether the medium contributes a nonzero response in the tested regime, or approaches a null/impotent limit.

The new addition is the third axis. A medium can be present in the working representation yet have zero observable response; it can also have a nonzero response that is still representable as timesheet flexure. Neither case automatically requires an independent third state-bearing sector.

This is an additive refinement of the existing primitive-economy gate in [issue #1486](https://github.com/Satobloc/HsH/issues/1486), not a replacement or duplicate.

## 2. Four response/representation states

| State | Representation | Response | Interpretation |
|---|---|---|---|
| M absent | No medium state | None | Two-primitive worldtube/timesheet baseline |
| M present, null response | Medium retained as a model slot | Null/impotent on the declared domain | Observationally baseline-equivalent on that domain; not proof of ontological absence |
| M present, nonzero but absorbable | Medium response maps into timesheet flexure or an extended timesheet state | Nonzero | Representation refinement/equivalence, not an independent primitive |
| M present, nonzero and irreducible | Separate state/evolution and independent initial or boundary data | Nonzero | Independent third-primitive candidate, subject to evidence and holdout |

The source's perfect-superfluid statement is a conjectural null-response boundary, not an established general result about physical superfluids.

## 3. Conditional test contract

Before any physical calculation, an actual measured system and dataset must be identified. The minimum missing objects are a source-defined medium state space (M), a response map (R_M) with domain, units, boundary conditions and coupling to an observable, a baseline worldtube/timesheet readout map, and an explicit medium-to-timesheet representation map.

1. **Null-response gate:** specify the regime in which (R_M) is null and show, through an explicit reduction map, that the augmented readout reduces to the declared worldtube/timesheet baseline. This is a dynamical/readout reduction, not silent deletion of a variable.
2. **Absorption gate:** provide a map from the medium description into an extended timesheet description and show that relevant dynamics and readout commute. A static fit or naming similarity is insufficient.
3. **Independent-sector gate:** retain a separate medium only if it has independently specifiable state/evolution or initial/boundary data and produces a calibrated observable distinction that cannot be reproduced by the allowed worldtube/timesheet representation under shared parameters.
4. **Holdout gate:** freeze shared parameters and nuisance treatment on calibration data, then test on independent acquisition blocks or conditions. If a medium-sensitive condition cannot be varied independently of worldtube/timesheet geometry, classify the comparison as NOT_IDENTIFIABLE.
5. **Falsification threshold:** derive it from actual instrument covariance and independent-unit structure. No numerical threshold is supplied without a real system and data.

This adds a response-null branch to the existing elimination/absorption/independent-sector decision layer in #1486 and the model-selection safeguards in [#1488](https://github.com/Satobloc/HsH/issues/1488).
