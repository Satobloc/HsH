# Source-typed `w` role gate for H(s)H model freezes

**Status:** source-provenance clarification and proposed acceptance-gate extension. This is not a theory promotion, physical prediction, or empirical result.

## Source chronology

- **2026-10-09:** a direct source uses `w=ct` as a time-length coordinate in the classical Minkowski limit.
- **2026-10-21:** a direct source records `cw=t` in a `++++` native convention; that message does not fully type `w` or provide a coordinate map.
- **2026-10-29:** a direct source uses `w=ct` within a branch-specific Forest Normalization context.
- **2026-11-08:** a later direct source provisionally treats `w` as a fourth spatial dimension, while allowing proper time to be distinct and to progress along `w`.

These statements are not yet reconciled. The later statement is additive and provisional; it does not by itself supersede the earlier conventions or supply a map.

## Required ModelFreeze witness

Add a coordinate-role witness recording:

- ambient dimension and metric signature;
- `w_role` and `time_role`;
- the exact `w`-to-`t` map, domain, codomain, units and scope, or an explicit unresolved status;
- the metric and normal definition used by `theta_4`;
- timesheet type and projection/composition maps;
- direct-source locators, dates, authorship class and supersession scope.

A candidate using `w` should not pass a comparison freeze while silently switching between time-length, native-coordinate and fourth-spatial interpretations.

## Conditional geometry

A smooth one-dimensional core embedded in a four-dimensional ambient manifold has a rank-three normal bundle. This is a conditional dimensional result, not a measured core radius, twist law or physical worldtube. A three-dimensional boundary and a two-dimensional worldsheet are distinct objects. Twist, contact surfaces and a specific normal-connection group still require explicit metric, embedding and map choices.

Existing formal work:

- [PR #873](https://github.com/Satobloc/HsH/pull/873): transverse-intersection dimension results.
- [PR #1133](https://github.com/Satobloc/HsH/pull/1133): carrier-slice projection and readout-descent results.

These are conditional Lean formalizations. They do not prove that the source-defined H(s)H maps exist or that the physical premises are true. No new Lean proof or physical validation is claimed.

## Freeze decision

`coordinate_role_witness` is a proposed addition to `ModelFreeze`, not an implemented schema change. The existing paired comparison-freeze architecture remains in place. No original SAT-O or Blockwave equation was altered, and no P2 system was selected.
