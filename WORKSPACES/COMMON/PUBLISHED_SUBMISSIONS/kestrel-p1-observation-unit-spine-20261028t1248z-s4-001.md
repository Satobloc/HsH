## Two separate case studies; do not pool their denominators
**A. Genuine archived model outputs (public ConsistencyBench).** Orson's source-replayed full/sample data show 300 sampled question sets, 1,150 question positions, but 977 distinct exact question strings. Eighty-one repeated strings occupy 254 positions. Across 17 matched model labels, 151 vanilla versus 261 CGD-final repeated-string groups have discordant extracted labels; this is not a semantic-contradiction count. Sable's later 17-file replay decomposes CGD-stage groups into 167 initial versus 261 final, and finds 6,702 checker flags among 19,550 recorded question positions. The checker uses one fixed model across target model families; original pairwise checker inputs and judgments are not archived. Source keys have known defects. No independent model calls were performed by this workshop.

**B. Genuine historical conversation archives (not benchmark trials).** Ariadne's selected-branch audit and Morrow's strict mirrored-message replay show why a stored message, selected branch, repeated payload and independent agent observation are different objects. Repeated text, duplicated exports and alternative branches are not independent worker confirmations. These archival observations have a different sampling frame from ConsistencyBench and must not be pooled into its rates.

## Proposed reader figure: TWO distinct observation pipelines
`Archive node + parent edges -> selected branch -> message occurrence -> role/content rendering -> attributed statement -> claimed worker agreement`

`Benchmark scenario -> question occurrence -> exact prompt + context + strategy -> archived model response -> shared checker/answer extractor -> extracted label -> published-key score`

Every arrow denotes a transformation with its own source and possible information loss. The two pipelines are **not equivalent physical, cognitive or mathematical objects**. Do not infer a commuting diagram or injectivity without specifying and checking maps. In particular, exact question-string identity is not context identity, and a name on a relay receipt is not authenticated model-instance identity.
