## Stable typed glossary and mapping
- S: proposed system or mechanism. X: specified admissible input domain. Y: output domain. f_S:X->Y: deterministic output rule, when one is actually defined.
- O:Y->Z: declared observation/readout map. T subset X: tested input set. A history-dependent or stochastic model requires a different typed object, such as a conditional output distribution given histories, not automatic reuse of f_S.
- Exact extensional equality E_X(A,B): for all x in X, f_A(x)=f_B(x). This is a definitional relation, not a discovered physical theorem.
- Observational equality E_O(A,B): for all x in X, O(f_A(x))=O(f_B(x)). This depends on O and X; equality on finite T is weaker.
- ULoD: proposed 'ultimate limit of detectability'; no instrument class, physical noise bound, operational protocol, or information-access class is specified in these sources.
- C(S): a proposed consciousness predicate, whose definition and relation to O are NOT supplied. 'Consciousness' and 'cognition' cannot be substituted as synonymous typed observables without definitions.
- F(S): PDF appendix's predicate 'functionally equivalent to a human'. Its reference human, observation domain and modal interpretation are not fixed.
- Source-role vs composition: a USER node authenticates where text entered the conversation, not whether the user wrote it from scratch.

## Original versus translated propositions
P1 USER-ROLE: output matching for all admissible inputs suffices for *functional* equivalence. Formal translation: E_X is equality of functions on a specified domain. The assistant adds 'identical for all scientific purposes' without a defined observable family or explanatory scope.
P2 USER-ROLE: practical equality and ultimate indistinguishability are distinct. Assistant frequently moves between exact equality, finite-precision equality and all-conceivable-observer equality without specifying O, T or the measurement class.
P3 NATHAN DIRECT user turn: agnosticism about whether AI is conscious is the intended debate intervention. Assistant: claims a universal proof that no one could know, including humans, without showing observationally equivalent systems with different C values under every relevant admissible observation.
P4 HISTORICAL PDF: `F(x) and F(y) -> possibly(C(x) iff C(y))`; under S5, possible P implies necessarily-possible P. Even granting both statements, the appendix's later `F(x) -> possibly C(x)` does not follow. Equal truth values could both be false; the modal equivalence axiom alone does not force either consciousness predicate true.
P5 PDF 'Epistemic Checkmate' is asserted, not established: from output equivalence alone one cannot conclude that consciousness is empirically undecidable under every possible observation. The missing assumption is an explicit independence/non-identifiability of C with respect to the entire admitted observation family.
P6 A mathematical proof of a source-conditional extensionality identity would not validate its translation into a consciousness claim, nor certify originality.
