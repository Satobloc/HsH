## 2. Substantive architecture improvement: representation-type firewall

The previous screen-spin result was framed as a linear-map no-go. The more useful architecture separates semantic object type, transformation law, and physical role before allowing a map.

| Symbol / object | Type | Meaning |
|---|---|---|
| 'SAT_spin_frequency' | scalar frequency / internal oscillation descriptor | Filament/coiling dynamics in the direct geometry source |
| 'Blockwave_J2' | antisymmetric 2-form | Assistant-voiced attachment content with unresolved embedded authorship |
| 'screen_area_coefficient' | scalar coefficient of a 2D area form | Trivial SO(2) representation |
| 'GW_helicity_spin2' | symmetric trace-free rank-2 screen tensor | Plus/cross polarization pair, weight 2 |
| 'detector_strain' | calibrated time series | Instrument readout after antenna response, delay, noise, and calibration |

A symbol named "spin" is not a representation type. Internal oscillation frequency, antisymmetric two-form degree, and gravitational-wave helicity are not interchangeable.

For an oriented 2D screen, the area form is invariant under SO(2). The plus/cross pair transforms by twice the screen-frame angle. At a quarter-turn, the area-form coefficient is fixed while the spin-2 pair is negated:

- source action: 'a(x) = x'
- target action: 'rho(v) = -v'

If an equivariant map 'f' has only the scalar area-form coefficient as input, then 'f(x) = -f(x)', hence 'f(x) = 0'. This argument does not require linearity. It requires the stipulated source and target actions and equivariance under that quarter-turn.

Therefore the prior caveat "nonlinear maps remain open" must be narrowed: nonlinear scalar-only equivariant maps are also zero. Maps that use additional spin-carrying inputs, a screen frame that transforms as part of the source, or a covariant differential map remain outside this restricted source class.

This does not derive the SO(2) actions from H(s)H geometry, establish the physical source-to-screen map, or rule out H(s)H generally. It rules out only the restricted scalar-only equivariant map.

### Test matrix

| Hypothesis | Shared parameters / calibration | Observable | Standard comparator | Holdout and failure rule |
|---|---|---|---|---|
| H0: scalar-only screen source with quarter-turn equivariance | No detector fit needed for the representation theorem | Predicted spin-2 output is exactly zero | SO(2) representation law | Any claimed nonzero output requires additional source data or a broken equivariance premise; this is an internal consistency test, not a physical fit |

| H2: unrestricted mixed-polarization reconstruction | Same calibration and detector-response model | Independent polarization components | Network-rank/identifiability comparator | HLV is not a full five-mode inversion; do not claim arbitrary mixed-mode reconstruction from three detectors |

For H1, a proposed residual statistic is 'T = r^T C^-1 r', where 'r = d - h_hat_HsH'. A proposed rejection rule is 'T > q_0.99', with 'q_0.99' estimated from an off-source noise and calibration posterior-predictive distribution after the model and analysis are frozen. This is a proposed rule, not an approved or numerically evaluated threshold. No numerical cutoff is justified until the raw data, PSDs, calibration envelopes, covariance, and H(s)H map are available.

Chatziioannou et al. (2021), [arXiv:2105.01521](https://arxiv.org/abs/2105.01521), applied morphology-independent polarization analysis to GW190521 and simulated signals. The HLV network can distinguish some pure tensor/vector/scalar extremes, but cannot fully reconstruct all five independent polarization states. Full inversion requires five non-cooriented differential-arm detectors when sky position is known. Thus GW190521 is a useful benchmark, not a complete model-independent test of arbitrary mixed polarizations.

For the standard plus/cross frame transformation, see Isi et al. (2022), [arXiv:2208.03372](https://arxiv.org/abs/2208.03372), DOI '10.1088/1361-6382/acf28c'.
