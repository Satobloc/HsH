## 1. New result

The existing H950 timing audit converted the published H1/L1 arrival delay into a baseline-projection length and fraction. This addendum carries the same measured interval through the inverse angular map.

For the LIGO Hanford-Livingston baseline, the published delay maps to an angle of **46.4399 degrees** between the wave-propagation axis and the unoriented detector-baseline axis. The source-direction axis is opposite the propagation vector, but the angle to an unoriented baseline axis is unchanged. Propagating the GWOSC caption's asymmetric displayed endpoints gives **42.3494 to 49.5212 degrees**.

This is a baseline-relative angular band, not a sky-location posterior, not a 90% credible region, not SAT theta-four, and not a new measurement. The GWOSC caption does not assign a coverage or confidence interpretation to the displayed delay bounds. The angular endpoints inherit that unresolved semantics.

## 3. Reproducible calculation

The standard two-site plane-wave timing relation constrains the signed projection of the wave-propagation unit vector onto the baseline. Using the magnitude to report the angle to the unoriented baseline axis, while retaining the observed L1-first/H1-later sign separately:

`mu = c * abs(Delta_t) / B`

`alpha = arccos(mu)`

The baseline light-travel time is:

`B/c = 10.012846152224 ms`.

| Published delay endpoint | Projection fraction | Angle to baseline axis |
|---:|---:|---:|
| 6.5 ms | 0.6491660714 | 49.52124330 degrees |
| 6.9 ms | 0.6891147527 | 46.43992534 degrees |
| 7.4 ms | 0.7390506043 | 42.34939569 degrees |

Thus the displayed asymmetric delay interval maps to:

- lower angle endpoint: 42.34939569 degrees;
- central-value angle: 46.43992534 degrees;
- upper angle endpoint: 49.52124330 degrees;
- full angular width: 7.17184761 degrees.

The local derivative at the central value is approximately `-7.89651482 degrees per millisecond`. This is a local sensitivity, not a statistical standard error.

A 50-decimal-place `mpmath` replay independently reproduced the baseline norm, light-travel time, projection fractions, and angles. No invented physical inputs were used.

Minimal standard-library reproduction:

```python
from math import sqrt, acos, degrees

r_h1 = (-2161414.92636, -3834695.17889, 4600350.22664)
r_l1 = (-74276.0447238, -5496283.71971, 3224257.01744)
b = tuple(x - y for x, y in zip(r_h1, r_l1))
B = sqrt(sum(x*x for x in b))
c = 299792458.0
baseline_ms = 1000.0 * B / c

for delay_ms in (6.5, 6.9, 7.4):
    projection = delay_ms / baseline_ms
    angle_deg = degrees(acos(projection))
    print(delay_ms, projection, angle_deg)
```

## 4. Identifiability consequence

The timing-only observation map, with n defined as the wave-propagation unit vector and b = r_H1 - r_L1, is:

`f : S^2 -> R`, `f(n) = b dot n / c`.

For a fixed signed delay, its inverse image on the unit direction sphere is a small circle. The displayed delay interval thickens that circle into a spherical band. The measured sign, with a declared baseline orientation, selects the oriented side; it does not determine the azimuth around the baseline.

Therefore:

- **Identified by timing alone:** one signed baseline projection, with the source-caption bounds and their unresolved coverage semantics.
- **Not identified by timing alone:** the full source direction, azimuth around the baseline, polarization, or a unique sky position.
- **Not identified at all by this timing observable:** intrinsic H(s)H worldtube thickness, twist, contact surfaces, or a source-to-medium constitutive law.

The GWOSC page separately displays sky maps from four localization pipelines. Those products use additional information, including detector response and waveform/polarization constraints. They must not be conflated with the timing-only band.

This gives the P2 architecture a sharper separation between (a) the scalar timing channel, (b) antenna-pattern and waveform channels, and (c) the full network sky posterior. These are different observation maps, not interchangeable descriptions of one measurement.
