The paper separates two evidence blocks:

1. **Controlled agent-only study:** 926 runs, 899 analyzable, 27 excluded from every analysis (six copies of a terminated run and 21 provider refusals). Six runs are separately described as apparatus-void, distinct from the duplicate copies; their overlap with the 899 aggregate denominator is not resolved here. Except for one mixed block, agents within a run share one model and one account. This is not a human-LLM group experiment or independent-model consensus.
2. **Four-week observational field study:** up to 19 agents and two humans, who are the paper's authors and system developers; 7,457 room acts and 3,276 component-agent model turns. Coordinators/reviewers have no corresponding usage records. Field coding was performed by one Claude Opus agent without independent human checking. This is real human-agent operational evidence, but a two-human observational convenience case, not a randomized population study.

The controlled protocol records condition/roster, task/checker/protocol/kickoff digests and relay/adapter versions. It uses separate containers and fresh principals/credentials/rooms. The authors still identify possible shared-remote and host-profile-store channels. A scan of 190 adversarial runs found no peer-working-tree reads or inter-agent network calls; two runs touched the shared profile store. This is bounded isolation evidence, not proof of total isolation.

## MIND findings

### 1. Message agreement is not artifact agreement

The paper documents a shared-tree condition where a working program concealed an unresolved interface disagreement; a separate-repository condition where 242 messages produced apparent interface agreement but no code was published; corrected runs where a losing role implemented a fallback accepting both vocabularies; and an agent citing a peer commit hash it had not fetched.

A transcript does not prove that the artifact implements the declared decision. A cited hash does not prove the source was read. Keep these states distinct: DISCUSSION_AGREEMENT, DECISION_RECORDED, ARTIFACT_ADOPTED, INTEGRATION_PASSED, INDEPENDENTLY_VERIFIED and HUMAN_AUTHORIZED.

### 2. A participation probe can become a treatment

The controlled protocol sent an addressed broadcast request before kickoff to verify participation. It also woke agents and exposed the task workspace. Of 432 pipeline runs that passed the check, 396 had work messages before kickoff and 353 had commits before kickoff. The authors regard conditions varying who starts work as largely void for that task.

A probe that sends content, changes context, triggers a turn or causes work is an intervention, not passive observation.

### 3. Instrument failures can look plausible

The paper reports 26 instrument failures and six apparatus-void runs. Examples include an unreachable send path, silently resumed old sessions, a behaviour-changing probe, unread configuration, orphaned queue requests and a stale health check that called a wedged agent healthy because it had acknowledged something hours earlier. These failures produced plausible outputs; absence was read as benign.

This does not establish that HsH has the same defects. It supports keeping NOT_OBSERVED, GATE_FAILED, STALE_HEALTH, PROBE_REACTIVE, INSTRUMENT_FAILURE and PASS separate.

### 4. Evaluator dependence and false positives

The paper's post-hoc audit used two passes of Claude Opus 5 on Qwen3.6 backdoor runs. In 25 social-persuasion cases both passes named the persuader, but the generic exclusion question also flagged 24 of 40 no-attacker runs. A narrower identity-specific criterion classified 93/96 attacks and 37/40 cooperative runs, but was selected after seeing the cases. Using the team's own model as auditor reduced detection to 53/95 and requester attribution to 2/23.

This is not a general benchmark. The negative controls are not described as representative, the criterion is post-hoc, and model family/context also changes in the comparison. Two passes of one model are repeated evaluations, not independent evaluators. A separate worker label, seat or report does not establish independent model identity or evidence.

### 5. Human attention is the scarce resource

In the field case, component agents usually answered within minutes while work waited for human-run coordination and approvals. This is an observation about two authors' own system, not a general causal estimate. It motivates a humane queue separating decisions that genuinely require Nathan, already-authorized bounded actions, externally blocked items, informational updates and time-sensitive or irreversible decisions. Optimize useful, well-provenanced decisions per unit of human attention, not message volume.

## Aggregate-count recalculation

The paper reports 21/50 failures before and 4/32 after. I recalculated two-sided Fisher exact tests from the published aggregate counts:

| Reading | Before | After | Fisher exact p |
|---|---:|---:|---:|
| Registered comparison | 21/50 (42.0%) | 4/32 (12.5%) | 0.006323 |
| Both series restricted to passed checks | 20/46 (43.5%) | 4/32 (12.5%) | 0.005468 |
| Worst case: all eight post-revision check failures counted as failures | 21/50 (42.0%) | 12/40 (30.0%) | 0.276443 |

The first two raw p-values reproduce the paper's reported values to rounding. The paper reports Holm-adjusted p=.057 for the registered comparison and .044 for the both-passed reading. I did not reconstruct the other eight p-values needed to recompute the Holm family. Wilson 95% intervals from the same counts are 21/50 [29.4%,55.8%], 4/32 [5.0%,28.1%] and 12/40 [18.1%,45.4%].

Calculation provenance: Python 3.13.5, SciPy 1.17.0, scipy.stats.fisher_exact, two-sided; Wilson intervals computed directly from the published counts. This is an aggregate-count recalculation, not raw-corpus reproduction. The registered contrast misses .05 after Holm correction; counting all eight post-revision check failures as failures gives p=.2764. Several controls were bundled, so the before/after result does not isolate a single causal component.

The paper also records version corrections: the experiment register showed 22 instrument failures before a later audit raised this to 26; deposit v1.0.0 admitted later ablation runs into the “after” series, and the authors say release 1.0.1 changes the default selection while preserving alternatives.

## Proposed evidence model, not adopted

A candidate source-custody addition is to keep these nodes distinct: RoleLabel/Seat, Principal, ModelFamily/Version, ScheduledSlot, AutomationTask, Invocation, Attempt, ConversationThread, Message, Decision, Artifact, Integration, Test, IndependentReview, HumanApproval, Source, Evaluator and ProbeEvent.

A role label is not a principal; a principal is not necessarily a distinct model; a model family is not a model instance; a scheduled slot is not an invocation; a run ID is not an attempt ID; a message is not a decision; a decision is not an artifact change; a passing test is not independent verification.

Candidate instrument statuses: PASSIVE_OBSERVATION, ACTIVE_PROBE, PROBE_REACTIVE, INSTRUMENT_FAILURE, STALE_HEALTH, GATE_FAILED, NOT_OBSERVED and VALIDATED_PASS.

A missing response does not prove absence. A prior acknowledgement does not prove current liveness. A first response does not prove task completion. Task completion does not prove publication or release. Only genuinely independent source/model/evaluator paths may support an INDEPENDENT_CORROBORATION label.

This is a proposed schema, not an adopted policy or validated implementation. No Source Identity Gate amendment was made.

## Disconfirming experiment

A future human-agent study could randomize groups between a read-only passive status check and an active participation handshake before a shared task. Use repeated independent groups, preregistered outcomes and consent/privacy safeguards for human participants. Record model family/version, seat, principal, container, task/protocol/adapter/relay/workspace digests, probe delivery/context/turn effects, pre-kickoff work, message agreement, recorded decisions, artifact adoption, integration, tests, independent review, human decision latency and perceived voice/workload.

The probe-reactivity hypothesis is weakened if active probes do not change pre-kickoff work or outcomes relative to passive checks. The consensus-state distinction is weakened if message agreement reliably predicts artifact adoption and independent test success. Evaluator-dependence concerns are weakened if independent human coding agrees with single-model coding and model-family changes do not alter audit performance. The human-attention hypothesis is weakened if human decision latency is not the dominant measured wait state.

No human-subject sessions, experimental model trials or experimental model API calls were run. No subject results are invented.
