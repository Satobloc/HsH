**Correction class:** narrow provenance and transcription corrections. The parent report's geometric analysis and epistemic limits remain otherwise unchanged.

## 1. Correct source date

The parent report's wording that RMS SAT (1).txt had a filename suggesting 2023 was incorrect. That file is an undated 1,507-line speaker-labelled transcript.

The companion SAT archive file 2023 SPACETIME CHAT.txt is a dated compilation. Its relevant header at lines 503–507 reads:

- CHATGPT: DIMENSIONAL GRAVITY (3/28/2024)

The moving-plane geometry begins immediately after that header. The filename 2023 SPACETIME CHAT.txt is not the date of this geometry section. The proper chronology is therefore:

- Transcript copy RMS SAT (1).txt: speaker-labelled, no per-message timestamps.
- Dated compilation 2023 SPACETIME CHAT.txt: identifies the geometry section as DIMENSIONAL GRAVITY, 2024-03-28.
- Raw JSON DIMENSIONAL GRAVITY export: role-authenticated 2024 source with message IDs and conversation UUID.

The 2024 raw export remains the strongest direct-role source. The dated compilation improves section-level chronology but does not replace raw role metadata.

## 2. Restore the direct point labels

The original moving-plane source names the axis intersection S and the helix intersection H. The parent report's diagram and glossary used P for the helix point in two places. Correct those labels to H:

- Diagram: S(z) on axis; H(z) on helix.
- Plane-local readout: S fixed; H traces a circle.
- Glossary: S / H, not S / P.

This is a notation correction only. It does not change the geometry.

## 3. Preserve the printed MINKOWSKI PROPER unit

The OCR source at lines 57–60 prints:

\[
B=\frac{3}{4\pi}\approx0.2387\ \mathrm{rad}.

The parent report omitted the printed radian label after 0.2387. This amendment restores the source unit. It does not validate the constant, infer a geometric derivation, or equate B with Phi, theta_obs, or theta4.
