## 1. Nathan Direct: five representational objects

The direct statement names five objects in a specific order:

1. **Primary — observation.**
2. **Secondary — physical working orrery / hands-on demonstration.**
3. **Tertiary — precision dynamic geometry as a software model.**
4. **Quaternary — precise static diagram.**
5. **Pentary — mathematics.**

The controlling distinction is explicit: the theoretical object is the geometry; mathematics provides precision, calculation and fitting but is not the physical or theoretical object. A precise geometric plot, hostile fidelity review of that exact plot, and display of the plot with the associated file are required for Factory Floor admission. The same principle applies to papers making geometric claims.

The five labels are directly sourced. Calling them “representational levels” or a “hierarchy” is a reasonable operational description, but the source does not define them as nested sets or specify a sequence of projection maps. The ordinal order does not establish that every project must fabricate all five objects, nor that one is a lossless encoding of the previous one.

The current Factory Floor specification adds a detailed plot checklist and conditional requirements: the quaternary plot is the minimum visual deliverable; a tertiary executable model is required when the claim concerns dynamics or response; primary observations and secondary demonstrations are required when relevant. These are useful operationalizations of the direct rule, not additional Nathan-authored mathematical definitions.

## 2. Nathan Direct: four incorporation tiers

The four tiers are a sequential hypothesis-admission rule, not another name for the five representational objects.

- **Tier 1 — geometric admissibility:** a proposal must be suggested by, preferably required by, or one of a small number of alternatives constrained by the actual geometry.
- **Tier 2 — tentative explanatory candidate:** it passes Tier 1 and offers a neat explanation with multiple intuitive interaction surfaces.
- **Tier 3 — official working-hypothesis candidate:** it passes the first two tiers and, without being prompted or separately invoked, unexpectedly explains otherwise unrelated phenomena as a consequence of the same construction, preferably across multiple sectors.
- **Tier 4 — structural membership:** removing or changing the structure breaks or predictably distorts the other model numbers by a predictable amount.

The source makes the progression explicit: higher tiers require the earlier tiers. Tier 3 is not awarded for post-hoc analogy or a collection of separate fits. Tier 4 is a counterfactual dependency criterion, not a claim that the model is physically true.

The current directive adds an operational Tier 4 protocol: define the intervention, hold other conditions fixed where appropriate, derive expected output changes, and document degeneracies or compensating changes. This is a sensible test design, but those detailed controls are an assistant-authored operationalization. The direct source does not yet define the model's intervention operator, the full output vector, “all the other numbers,” or a tolerance for “predictable amount.”

The geometry-first Factory Floor gate and the four incorporation tiers are cumulative but distinct. A plot passing Factory Floor does not automatically pass Tier 1 as a new hypothesis; Tier 1 candidacy does not automatically clear Factory Floor. The current documents preserve this distinction correctly. Describing the two as a “two-dimensional gate” is a useful assistant synthesis, not a source-defined coordinate space.

### O0-A, pages 11–12

The O0-A mode ladder uses these labels and descriptions:

- **Mode 1 — True Block:** the baseline freeze-out; filament kinematics are held fixed and the moving three-dimensional resolving surface supplies the changing slice/readout.
- **Mode 2 — Triggered Dynamics:** passage of the resolving surface permits local filament-parameter adjustments, with average curvature denoted by ⟨K⟩ pegged to the GR target and minimal filament changes back-solved.
- **Mode 3 — Crystallisation:** the block resolves/solidifies during the sweep; filament dynamics are determined during that process and afterward constitute fixed history, with the resolving surface serving as an ordering label.

O0-A states that higher modes inherit the results of lower modes while relaxing a specific freeze-out. It also identifies Mode 2 use in later module work. This is an inheritance claim in prose; no state spaces, projection operators, preserved quantities, or composition conditions are supplied.

### Same Big Paper, page 103

A later “Interpretive Modes of SAT” table uses different labels:

- Mode 1 — True Block.
- Mode 2 — Semi-Dynamic.
- Mode 3 — Solidification Front.

The page also states: “All SAT module construction must occur strictly in Mode 1.” That is in tension with O0-A's earlier description of Mode 2 use in Modules 6 and 8. The conflict is inside the same 171-page document and cannot be resolved merely by choosing the later page.

### Deployment Guidelines

The separate SAT.4D Deployment Guidelines use “Semi-Dynamic Block” for Mode 2 and “Solidification Front” for Mode 3. They describe Mode 1 as the default, allow marked Mode 2/3 use in restricted contexts, and prohibit Mode 3 in falsifiability-grounded SAT.O modules.

The file-index metadata gives the Deployment Guidelines a creation date of 2025-06-11, while the document itself is labeled July 2025. The Module O0-A TeX file is indexed with a 2025-06-20 creation date. These dates do not establish a reliable precedence order.

### Source-version conclusion

The source contains two naming families:

| 1 | True Block | True Block |
| 2 | Triggered Dynamics | Semi-Dynamic / Semi-Dynamic Block |

The labels may refer to related or evolving descriptions, but exact synonymy is not established. The current Nathan Direct transcription's hybrid phrasing (“Triggered/Semi-Dynamic” with “Solidification Front”) should not be quoted as the verbatim naming of one source version. Preserve the variants until the original document lineage or an explicit correction resolves them.

The Mode 1 “True Block” is methodologically qualified by the direct November 3 statement: it is a formal working frame, not a conclusion about ultimate ontology. The source does not authorize turning Mode 1 into a metaphysical claim that the universe must literally be a static block.
