## 4. Corrections and type obligations, kept separate from originals

A standard differential-form typing of the Blockwave potential is:

\[
F_{\rho\sigma}=2\nabla_{[\rho}B_{\sigma]},
\qquad
J^{\mu\nu}=
\frac12\epsilon^{\mu\nu\rho\sigma}F_{\rho\sigma}
=
\epsilon^{\mu\nu\rho\sigma}\nabla_\rho B_\sigma
\]

This assumes \(B\) is a one-form and the connection is torsion-free. It is a standard typed candidate, not a replacement of the archived equation or an assertion that the Blockwave model is adopted.

The geometric support types must remain distinct:

- \(\Gamma^1\): a one-parameter curve/core path.
- \(S^2\): a two-dimensional worldsheet, as in the Nambu-Goto comparator or a thin-string interpretation of a two-form current.
- \(W^4\): a full-dimensional finite-core worldtube/support, if that is what the direct source intends.
- \(\Sigma^3\): the three-dimensional time slice/bulk.

For transverse submanifolds in a four-dimensional ambient space:

\[
\dim(A^k\cap\Sigma^3)=k+3-4=k-1.
\]

Therefore a one-dimensional curve intersects in points, a two-dimensional worldsheet in a one-dimensional trace, and a full-dimensional support region in a three-dimensional slice. A loop from \(W\cap\Sigma\) is dimensionally appropriate if \(W\) means a two-dimensional worldsheet, not if it means a four-dimensional finite-core support. The Blockwave prose uses these meanings without a stable type distinction.

The phrase “four-dimensional filament” also needs an intrinsic-dimension/ambient-dimension distinction. A one-dimensional curve embedded in four dimensions is not a four-dimensional support. A full-dimensional four-dimensional carrier has no normal directions in the same four-dimensional ambient space; finite-core structure would need to be internal or use a different ambient construction.

No source-grounded map is yet defined for:

\[
\Gamma^1 \longrightarrow W^4,
\qquad
W^4\times\Sigma^3\longrightarrow I^3,
\qquad
I^3\longrightarrow\text{observed trace}.
\]

The Blockwave current-to-worldtube map is also absent.
