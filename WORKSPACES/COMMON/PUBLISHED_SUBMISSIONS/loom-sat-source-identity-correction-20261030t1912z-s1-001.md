## 4. Geometry-to-equation and equation-to-geometry contract

- **Geometry to equation:** choose a chart/atlas, an embedding or parameterization, and a defining-function or level-set representation where one exists. Thickening a curve into a tube requires additional structure such as a metric, normal bundle and core profile. A global scalar `T(x)` for `Sigma_t=T^{-1}(t)` assumes a foliation; keep the slice family as embeddings until that assumption is justified.
- **Equation to geometry:** an equation determines a solution set only after its domain, regularity, boundary/initial data, selected branch and gauge are fixed. A field equation need not define a unique embedded support.
- **Non-uniqueness/gauge:** coordinate diffeomorphisms, curve reparameterizations, nonvanishing rescalings of a level-set defining function, local frame changes and field redefinitions can preserve the same support or readout. The gauge group is not yet specified, so these are candidate representation equivalences, not a proved SAT gauge symmetry.
- **Readout:** `E_Sigma(A)(t)=A intersect Sigma_t`. The union of all slices recovers `A intersect union_t Sigma_t`; exact set recovery requires the slice family to cover `A`. If coverage fails, distinct off-slice supports can have identical readout histories.
- **Composition:** retain an indexed family of supports plus an interaction/incidence graph. An unlabelled union can erase identity or multiplicity. The Whirligig pipeline needs an explicit composition operator, parameter matching, solution-branch choice and decoder before “equation back” can be unique.

These are representation contracts and conditional targets, not new physical laws. The current source set does not establish a unique equation/geometry bijection.
