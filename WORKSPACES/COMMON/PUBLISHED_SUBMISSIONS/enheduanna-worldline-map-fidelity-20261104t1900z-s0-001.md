## Executive finding

Three distinct constructions have been allowed to sit too close together:

1. **Worldline Universality (WU):** a historical representational-existence argument. It encodes events and relations in a collection of abstract worldlines.
2. **Back Hallways:** a historical cross-domain translation proposal, expressed in an assistant-authored file as maps between theory-specific observable spaces.
3. **Derivation Loop / Star-Shaped Derivation Map:** a current methodological protocol for transporting a relationship through independently constrained domains and testing held-out predictions.

Nathan Direct supports **conceptual continuity** from the older Back Hallways programme through the Loop and Star Map. It does not establish mathematical identity among these three constructions, nor does it identify the Star Map hub with the current H(s)H/Klein-Fabric geometry.

The central geometry-fidelity correction is that an abstract worldline encoding is not a finite-core physical worldtube. A map between them has not been defined.

## 2. What the Worldline Universality statement actually constructs

The historical episode labels its claim “Worldline Universality.” Its definitions are approximately:

- A system is S = (E,R), with events E and relations R.
- A worldline is a continuous map w: Λ → M.
- An encoding associates each event with a point or feature on a worldline and represents each relation through relative geometry or topology among worldlines.

The existence argument then permits arbitrary geometric/topological features, including crossings, curvature, torsion, winding, and oscillations, to be assigned so that the desired relation is represented.

That construction can support a **weak representability claim**: if the encoding space is sufficiently unconstrained, event/relation data can be represented by a sufficiently flexible collection of curves.

It does not, as written, establish:

- preservation of a specified metric or metric signature;
- preservation of causal order or causal character;
- satisfaction of either theory's equations of motion or field equations;
- conservation laws or local interaction rules;
- a measurement/readout map that recovers the original observables;
- injectivity, uniqueness, or a canonical choice of encoding;
- a shared physical model satisfying both theories' constraints.

The combined-system step S₁₂ = (E₁ ∪ E₂, R₁ ∪ R₂) merely unions the event and relation sets. It does not demonstrate that the union is dynamically consistent or belongs to a common physical system.

The episode description's strong compatibility language therefore exceeds what the displayed existence construction establishes. The phrase “canonical bridge” is unsupported: no uniqueness, universal property, or naturality condition is supplied. The existing Orson archaeology report correctly preserves the narrower distinction between representability and having solved quantum gravity or found a unifying equation; this audit does not redo that cognition work.

**Important type distinction:** the theorem's W is a collection of abstract worldlines used as an encoding. It is not automatically the current H(s)H finite-core worldtube. A thickening/embedding map from an encoding configuration to a physical worldtube would have to be separately defined and shown to preserve the relevant geometry and dynamics.

For clarity only, this report calls these different objects W_enc and W_phys. These are provisional audit labels, not adopted canonical symbols.

## 3. Back Hallways: the old map and its conditions

The assistant-authored file defines a primitive set P, projections πᵢ: P → Oᵢ, and the hallway

    Hᵢ⟶ⱼ := πⱼ ∘ πᵢ⁻¹.

It calls this a “functorial map,” but no categories or morphisms are defined. The file also allows a “pseudo-inverse if many-to-one.” A pseudo-inverse is a chosen reconstruction rule, not a unique inverse.

The file's stated round-trip expression,

    πᵢ ≈ πᵢ ∘ πⱼ⁻¹ ∘ πⱼ,

has type P → Oᵢ. It is a reconstruction/residual check on the primitive state space P, not by itself an observable-space round trip on Oᵢ. A round trip on observables would require an explicitly restricted composition Hⱼ⟶ᵢ ∘ Hᵢ⟶ⱼ, and that composition is unavailable unless the inverse/relational conditions are supplied.

The existing Back Hallways source-fidelity report already treats the fiber-constancy/injectivity condition. This report does not duplicate that result. The new point is that the later Loop/Star Map still needs its own typed maps; it cannot inherit them by analogy.

## 4. Current Loop and Star Map: a process graph, not yet a mathematical composition

The current process document describes the stages E → G → Dᵢ → G′ → E′, and a common hub H feeding spokes Sᵢ.

This is a useful workflow sketch, but the arrows are not yet defined as functions or relations. In particular, the source does not specify:

- the domain and codomain of each arrow;
- whether each arrow is total, partial, injective, surjective, or many-to-one;
- which metric, units, frame, orientation, or gauge transformations are preserved;
- what invariant defines “the same relationship” after transport;
- how G′ is related to G;
- what information is lost at each domain projection;
- the composition law and its admissible domain;
- which independent measurements constrain each spoke.

The hub H is also an unqualified local label. It must not be conflated with H(s)H, Hubble-related symbols, the historical 4DHH-UC Lagrangian hub, or the current Klein-Fabric model. No canonical hub symbol or physical identity is adopted here.

The Star Map is a **methodological graph of mathematical transports**, not a star-shaped physical manifold and not a collection of physical tunnels. The direct phrase “mathematical corridors” supports that category.

## 5. Proposed map contract

The following is a type-signature proposal for future source-faithful work, not a canonical equation or adopted theory.

~~~text
Historical WU:
  Theory model M1 --enc1--> W_enc <--enc2-- M2 Theory model
  [representational encoding; no physical structure-preservation map supplied]

Historical Back Hallways:
  P_BH --pi_i--> O_i
  P_BH --pi_j--> O_j
  H_ij := pi_j o inverse(pi_i)
  [requires restricted inverse or a relation/quotient]

Current Loop:
  E --g--> G --t_i--> D_i
  {D_i : i in anchors A} --r_A--> G'
  G' --q--> E'

Current Star Map:
  X_hub --s_i--> O_i
  anchors A -> infer and freeze X_hub
  holdouts J -> predict s_j(X_hub)
  independent readout m_j(S_j) -> compare
~~~

Required conditions before any of these diagrams can be promoted:

1. Give every object a stable type and every arrow an explicit domain/codomain.
2. Distinguish the common model/hub state space from physical geometry. The provisional label X_hub avoids silently reusing H.
3. Define each spoke sᵢ as a forward map or explicitly as a relation. Define an independent measurement/readout map mᵢ from an identified system to its domain observables.
4. Partition anchor domains A from holdouts J. Infer the hub from anchors only, freeze all maps and parameters, and compare held-out predictions against independent readouts without refitting.
5. Record non-identifiability. If a projection is many-to-one, do not write a global inverse. A pairwise map exists as a single-valued function only under an appropriate fiber-constancy condition, or after a declared quotient/relation construction.
6. State the conditions under which maps compose. A round-trip identity is a separate property, not an automatic consequence of drawing a loop.
7. For W_enc → W_phys, define the thickening/embedding map and specify preservation of metric, causal order, orientation, internal structure, interactions, and readout. No such map is presently supplied.

The Cross-Formalism Index already provides the appropriate metadata fields for recording these conditions. No new canonical symbol or relation edge is registered by this report.
