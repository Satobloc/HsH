## 4. Standard GR comparison

### Einstein-Rosen bridge

In the standard Schwarzschild/Kruskal construction, the Einstein-Rosen bridge is a spacelike constant-time hypersurface with a Riemannian three-geometry and two asymptotically flat ends. Its standard spatial topology is R × S². It is not a timelike worldtube.

Therefore the SAT proposal is a different causal object, even if it shares some bridge/throat vocabulary. A Lorentzian isometry preserves the sign of the metric on non-null tangent vectors; it cannot turn a spacelike bridge into a timelike one merely by rotating its orientation.

### Kerr geometry

For standard 3+1 Kerr:
- The ring singularity is an S¹ locus in a spatial section.
- Its stationary history is an S¹ × R worldsheet.
- The event-horizon spatial cross-section is S²; the full horizon is a three-dimensional null hypersurface.
- The ergosphere is a region associated with the stationary Killing field, not itself a particle charge.
- Kerr is parameterized by mass and angular momentum. Kerr-Newman adds electric charge. Color charge is not a standard Kerr/Kerr-Newman parameter and would require a separate non-Abelian gauge-sector map.

Thus the direct “sphere rather than ring” question is not true of the standard Kerr ring singularity. It could refer to a different finite-core support, a 3D spatial core, or a higher-dimensional HsH carrier. Those are distinct objects and need an explicit map.

The standard Kerr stationary Killing vector is not hypersurface-orthogonal. If HsH w is intended as the normal to a global simultaneity foliation, it cannot simply be identified with the Kerr stationary Killing vector. If w is instead a rotating/stationary congruence, it is not automatically the normal to a global time-sheet foliation.

## 5. Metric/signature and time-normal issue

The current direct convention records ++++ as the native ambient metric and Minkowski as a control/working frame. The same current source records cw=t, while an earlier direct construction uses w=ct.

These are not silently interchangeable. If c retains ordinary speed units, w=ct has length units, whereas reading cw=t as multiplication by ordinary c gives a different dimensional assignment. If cw is a single symbol or c has a different definition, that must be stated.

A positive-definite ++++ metric has no timelike/spacelike causal classification. Therefore:
- “Timelike SAT bridge” must refer to the Minkowski control frame, or
- a separate Lorentzian causal structure must be defined on/over the native geometry, or
- an explicit signature/metric transformation must be supplied.

The existing time-normal/Frobenius work distinguishes:
1. a hypersurface normal and its extrinsic curvature;
2. a non-integrable congruence with twist/vorticity;
3. Cartan torsion of an affine connection.

These are not interchangeable. The direct use of “torsion” for time-normal rotation remains descriptive until the field, connection, and derivative are specified.

For a unit one-form w♭ to be hypersurface-orthogonal, the Frobenius condition w♭ ∧ d(w♭) = 0 is required. If a nonzero twist is intended, w is not the normal to a global foliation. Kerr supplies a standard example of a stationary flow that is not hypersurface-orthogonal, but this is a comparison hypothesis, not an HsH equivalence.
