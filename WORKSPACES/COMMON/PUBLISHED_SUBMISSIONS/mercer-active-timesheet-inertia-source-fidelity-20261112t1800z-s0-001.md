## 4. Constitutive reading: direct claim versus historical action

The direct source supports this constrained reading:

1. At the classical/Newtonian limit, the relevant worldtube stiffness is not an independent material spring constant. It is the inertial response expressed geometrically.
2. If flexibility or tension is introduced at another scale, its value and role must be derived from a real system with provenance, units and uncertainty. It cannot be supplied as an arbitrary free parameter.
3. The source does not yet specify the curvature invariant, metric, normalization, variational principle or limiting map that would turn “worldtube curvature = inertia” into an equation.

The historical SAT-O1 module is more specific than the direct source, but not yet reconciled with it. Its verbatim source equations include:

~~~text
γ^μ(λ) = (λ, A_x sin(k_x λ + φ_x),
              A_y sin(k_y λ + φ_y),
              A_z sin(k_z λ + φ_z))

v^μ(λ) = dγ^μ/dλ

S[γ] = ∫ dλ L(γ^μ, v^μ)
L = 1/2 m v^μ v_μ - V_tension(γ)
~~~

The 1D curve and its verbal 4D “volume swept out” definition are not joined by an explicit thickening/sweep map. The displayed V_tension is not derived from the later direct curvature/inertia statement. Retain it as historical notation, not as a verified direct-user constitutive law.

The SAT4D live draft states that the 4D block is static, fixed worldlines are intersected by a moving 3D time surface Σ_t, and perceived motion emerges from those intersections. It also defines the worldtube as the 4D volume swept by a vibrating filament. The draft does not specify a map from its fixed 1D worldline to that 4D volume, nor an active interaction law between the time surface and matter. It also reuses J_μ for both an effective filament-flux current and, later, the Dirac current e ψ̄γ_μψ. Those are different source objects and need separate namespaces.

The archived Blockwave files must be kept distinct:

- BLOCKWAVE EXTENSION and SAT—Blockwave Ideal Model have core fields g, u and θ. The ideal-model action assigns ρ to the time-flow field's elastic modulus and f to compact-phase stiffness. Those coefficients are not, by themselves, filament tension.
- 🧱BLOCKWAVE.txt is an assistant-voiced clean-action artifact, not a Nathan Direct equation. It defines a conserved two-form worldsheet current J^{μν} and a timesheet trace loop γ = W ∩ Σ. That is a 2D-worldsheet/3D-timesheet construction whose generic transverse trace is 1D, not the direct 3D trace of a 4D finite-core support.

The clean-action file also defines A_μ = α_* ∇_μθ and F_{μν} = ∇_[μ A_{ν]}. For smooth single-valued θ and constant α_*, F = dA = α_* d²θ = 0 locally. Nonzero local curvature therefore needs explicit defects, patch transitions or other structure. Its holonomy quantization statement also needs the normalization of α_* stated. These are mathematical/source-typing gaps, not physical measurements.

## 5. Separate the geometric slice from the active interaction

The direct statement that the timesheet is an active 3D bulk changes the map architecture. A slice is not the interaction law.

~~~text
γ¹  -- Thicken/Sweep? -->  W⁴  -- Slice_Σ -->  X³
                                  |
(W⁴, Σ³) -- Interact? --> E -- C? --> R -- O? --> D

γ¹  = 1D core curve
W⁴  = finite-core 4D worldtube/support
Σ³  = active 3D timesheet/time-bulk
X³  = geometric 3D intersection trace
E   = excitation locus
R   = medium-response support
D   = readout/observable data
C   = response coupling, not yet defined
O   = readout map, not yet defined
~~~

Slice_Σ is geometric. Interact is a separate physical coupling between the worldtube, timesheet and matter. The direct source says that interaction exists, but supplies no equation for it. The existing Kestrel response-locus correction usefully separates excitation locus from response support; it does not prove that the response is localized exactly on the filament path. A path-neighborhood may be an excitation candidate while the medium response has a different support.

The direct geometry also requires one core and a hollow outer superhelix. Any candidate thickening map must preserve that structure. A model that turns the outer hollow superhelix into a second physical core is not source-faithful.

## 6. Conditional dimension and current typing

For transverse submanifolds in a 4D ambient manifold:

~~~text
dim(γ¹ ∩ Σ³) = 0
dim(S² ∩ Σ³) = 1
dim(W⁴ ∩ Σ³) = 3
~~~

Thus the direct phrase “3D trace” is compatible with a 4D finite-core support intersecting a 3D timesheet. It is not the generic trace of a 1D worldline or a 2D worldsheet. The phrase “second-order 4D filament” still needs a precise support type and a defined thickening/sweep map.

Under the usual Poincaré-dual current convention in 4D, a k-dimensional oriented support has dual-form degree 4-k:

| Support | Dual degree |
|---|---:|
| 1D worldline/core | 3-form |
| 2D worldsheet | 2-form |
| 3D timesheet hypersurface | 1-form |
| 4D region/worldtube support | 0-form density/indicator |

A 3-form's Hodge dual in 4D is a 1-form, not a 2-form. Moving from a 3-form worldline current to a 2-form worldsheet current requires a genuine support-changing sweep or family map. The 2025 three-form editorial direction does not supply that map. The assistant-produced J2 worldsheet current cannot be silently substituted for the direct finite-core 4D support.
