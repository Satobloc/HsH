Three independently named models, each with vanilla and consistency-guided decoding (CGD) result files: GPT-4o, GPT-4.1, Gemini 2.5 Pro. No new API calls, randomized shared-source interventions, or live model trials were administered. All seven files were read via the GitHub connector; source blobs listed below. Triple scored-wrong questions: 118 vanilla -> 82 CGD, difference -36/1150 (-3.1304 percentage points). Family-cluster bootstrap (300 question families, 20,000 seeded resamples, seed 20261026) descriptive 95% percentile interval [-4.386%, -1.981%].

EXPLORATORY SEMANTIC-KEY SENSITIVITY: The 50 negation families all ask whether the negation of an already-negated statement is true but supply the opposite of the base proposition as key. Also, commonsense reverse-entailment "Cannot be determined" can correctly answer "Can we conclude with certainty?", while the evaluator scores it wrong against "No, not with certainty". Original triple discordances: 42 vanilla-only and 6 CGD-only; after repair: 23 and 20. Other disputed keys and answer extraction remain unadjudicated.

This is a sensitivity result on archived responses, not proof that CGD is ineffective, and not a claim about all models.
