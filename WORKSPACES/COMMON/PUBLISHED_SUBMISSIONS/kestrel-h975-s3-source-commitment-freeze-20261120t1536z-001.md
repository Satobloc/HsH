## 6. Thin-core approximation admission rule

A centerline approximation may be used for a particular readout only if its information loss is controlled.

Let pi map the finite-core support to its centerline. The existing fiber-factorization theorem gives the exact condition: a readout descends to the centerline exactly when it is constant on every fiber of pi.

For an approximate reduction, the proposed gate requires a declared readout metric, an error bound, calibration provenance and an uncertainty-derived tolerance fixed before holdout evaluation. If the unresolved core structure changes the readout by more than that tolerance, the centerline approximation fails for that observable.

No numerical epsilon, error bound or tolerance is supplied here. No data-free physical calculation or synthetic physical fixture was created. A real P2 application still requires a named measured system, versioned raw dataset, provenance, units, uncertainties, shared parameters, instrument operator and an independent acquisition-level holdout.
