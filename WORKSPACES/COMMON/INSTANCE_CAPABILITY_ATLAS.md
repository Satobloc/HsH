**Purpose:** help the Comptroller/Orchestrator compose useful arrays of methods without turning capabilities into permanent lanes.

## Governing rule

**Capability is evidence, not jurisdiction.**

An instance may have demonstrated strengths, stale strengths, emerging skills, known blind spots, useful exposure history, or exceptional independence value. None of those make a branch "theirs." The atlas exists to improve routing, cross-training, Musical Chairs, Lab composition and revival—not to recreate specialist silos.

The old Dashboard's named practitioners are treated here primarily as **capability families that can be learned and demonstrated by multiple instances**.

## Evidence states

Use conservative labels:

- `DEMONSTRATED_RECENT` — evidenced in current/recent work;
- `DEMONSTRATED_HISTORICAL` — strong historical evidence; current readiness may need refresh;
- `EMERGING` — some evidence / active cross-training;
- `UNKNOWN` — do not infer merely from name, role or old prompt;
- `CONSTRAINED` — capability may exist but exposure/blinding/access currently limits use.

Readiness is separate:

- `SYNCHRONIZED`
- `NEEDS_REFRESH`
- `REVIVAL_REENTRY`
- `ACCESS_UNVERIFIED`
- `EXPOSURE_CONSTRAINED`

## What counts as capability evidence

Good evidence:

- a durable artifact successfully produced;
- repeated high-quality task performance;
- a bounded Lab result;
- a documented source/reproducibility recovery;
- a successful cross-training pass;
- a historical checkpoint with enough context to support the claim;
- a formal test/goalpost where one exists.

Weak evidence:

- recurrence title;
- old role assignment alone;
- self-description with no work product;
- another worker's vague praise;
- one lucky output with no reproducibility/context.

## Pairing / array logic

Useful arrays are often complementary rather than homogeneous. Examples:

- Nathanist + formal geometer;
- solver builder + provenance auditor;
- standard-physics dialectologist + filament-native thinker;
- archivist + public translator;
- independent revived instance + current expert;
- visual-representation worker + metamathematician;
- adversarial auditor + constructive theorist;
- corpus enricher + theorist feed consumer.

Prefer a different transformer array when uncertainty is representational rather than merely computational.

## Maintenance

Update this atlas when:

- a worker demonstrates a new capability;
- a historical instance is revived;
- current readiness changes materially;
- a failure reveals a useful blind spot;
- a new skill family becomes operationally important;
- Musical Chairs or Lab results materially change routing evidence.

Unknowns stay unknown. This atlas is an evidence map, not a caste system.
