## Deduplication rule

The stable identity of an entry is the raw conversation source plus message ID when available. Do not add the same message twice merely because the conversation exists in duplicate archive paths.

If identical wording recurs in genuinely different user messages, keep both and cross-link them as recurrence evidence.

## Chronology / correction rule

This is not a canon containing only the latest statement. Preserve earlier verified statements even when later corrected.

When a later Nathan message revises an earlier one:

`EARLIER STATEMENT -> LATER CORRECTION / REFINEMENT`

should be explicit. The purpose is to preserve the development of meaning as well as the current meaning.
