# Bibliography / Citation Sequence Roadmap

**Status:** ACTIVE planning surface  
**Authority:** Nathan directive, 2026-09-14  
**Purpose:** sequence citation/bibliography work so provenance improves without letting external literature steer unfinished reconstruction.

## Current priority order

### Phase A — internal-document bibliography first

Before an aggressive outside-literature bibliography push, build a thorough **internal-document bibliography / source ancestry map** across the three main repositories:

- **[[HsH]]** — current reconstruction/workspaces, live conversations, formalization, sandbox, coordination, viewer, indices;
- **[[GLASS]]** — historical/development archive, primary SAT/H(s)H documents, conversations, derivations, solver artifacts, project notes;
- **[RESOURCES]** — permitted reference/library material, paper collections, extraction/index infrastructure, bibliographic resources.

Goals:
- identify every internally cited or relied-upon scientific/mathematical source already present;
- connect claims/equations/constructs to the internal document that introduced or used them;
- distinguish Nathan-authored conceptual origin from later mathematical implementation or assistant/model formalization;
- recover missing citation metadata where possible;
- identify citation gaps without filling them aggressively from outside literature yet;
- make internal source ancestry auditable and machine-readable where useful.

### Phase B — SAT reconstruction / H(s)H working backbone

Primary theory work continues in sandbox. The aim is to reconstruct SAT cleanly and establish a nearly complete working H(s)H backbone before broad external prior-art/citation expansion is allowed to steer attention.

During this phase, outside literature may still be consulted for:
- standard mathematics/physics;
- empirical constraints;
- ordinary citation verification;
- already-needed standard references;
- narrow comparison/benchmark questions.

Potential prior-art cases are routed through Sable's controlled intake process rather than imported directly into forward theorybuilding.

### Phase C — exhaustive external bibliography / citable-works push

Once SAT reconstruction and the H(s)H working backbone are sufficiently mature, launch the larger bibliography programme:
- identify citable works comprehensively;
- build an exhaustive bibliography with stable metadata/links;
- map standard results and antecedents to internal constructs;
- classify relation type conservatively: standard background, direct mathematical tool, structural analogue, empirical constraint, historical antecedent, independent rediscovery, or uncertain relation;
- preserve chronology and avoid retrospective rewriting of internal conceptual development.

## Genealogical preference

Where mathematically and historically defensible, prefer citation chains that trace standard spacetime/geometric foundations back toward **Minkowski** and other primary/original sources rather than relying only on late secondary summaries.

This is a traceability preference, not a claim that every later mathematical tool derives directly from one source.

For each important mathematical ingredient, try to separate:
1. **Nathan conceptual origin / internal first appearance**;
2. **standard mathematical formalism eventually used to express it**;
3. **historical/public scientific antecedents or comparisons**;
4. **later SAT/H(s)H mathematical development and checks**.

## External-literature firewall

Ordinary literature search is allowed, but forward reconstruction should not quietly acquire new machinery merely because a close external formalism is found.

If an outside source appears to require special prior-art handling, workers should send only its bibliographic identity/source pointer and a minimal neutral description to Sable for disposition. Do not publish private quarantine-trigger criteria in ordinary project documentation.

## Deliverables

Near-term internal bibliography deliverables should include:
- repository-wide citation/source inventory;
- normalized bibliographic metadata where available;
- internal document ↔ cited work crosswalk;
- internal concept/equation ↔ source-document ancestry pointers;
- unresolved/missing citation queue;
- primary-source preference flags where a secondary source can be traced closer to an original result;
- coverage ledger stating which folders/documents have actually been checked.

Later external bibliography deliverables may include:
- exhaustive citable-works bibliography;
- relation-class map between SAT/H(s)H constructs and outside literature;
- chronology/priority evidence packets where needed;
- citation-ready exports in standard formats.

## Governance

Sable owns sequencing and workflow integration for this programme, with input from Mercer, Nathan Words, tagging/retrieval workers, revived consultants, and literature/research specialists.

Bibliography work should improve traceability, not become an alternate theory-development driver before the reconstruction/backbone is ready.
