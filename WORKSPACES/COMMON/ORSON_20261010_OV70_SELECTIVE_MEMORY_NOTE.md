# Orson OV-70: memory evaluation note (2026-10-10)
Exact computational experiment, not LLM inference: in 1,024 binary histories with q=.15 and ten uniformly weighted as-of queries, a six-checkpoint memory yields 40% structurally ambiguous queries but 89.8% answer coverage and 99.0% conditional accuracy under Bayes-optimal abstention (wrong-answer cost 1; abstention cost .2). A current-plus-last-change summary yields fewer structurally ambiguous queries (38.77%) but only 68.50% coverage and 98.41% conditional accuracy. Thus unique historical identifiability and probabilistic decision quality must be scored separately. More details: Orson OV-70 local research package. No physics implications.
