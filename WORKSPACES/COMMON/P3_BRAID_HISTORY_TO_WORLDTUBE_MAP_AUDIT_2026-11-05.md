## 3. The missing typed map

A mathematically honest candidate contract has to keep these objects separate:

1. **Physical history space** \(\mathcal H\): the set of admissible worldtube histories, with the actual support dimension, core structure, and interaction constraints supplied by source geometry.
2. **Observer/readout map** \(O:\mathcal H\to\mathcal Y\): the actual projection or readout into a specified slice/screen/configuration representation.
3. **Configuration path** \(\gamma\): a path in a specified configuration space, constructed from the projected strands/cores. Its parameter, labels, endpoints, and closure must be explicit.
4. **Topological readout** \(\beta\): a braid class only if the path really lies in a configuration space whose topology supports that braid object and the admissible equivalences preserve it.
5. **Physical interbraid constraint**: the source-defined restriction on allowed worldtube configurations. It may induce braid-sector protection, but it must not be replaced by a convenient collision potential, confining plane, slab, or hard-core rule that the source has not supplied.

## 4. The key distinction: projected braid versus physical interbraid

An ordinary braid-group element is not obtained merely by drawing helices or observing repeated relative rotation. A classical braid construction uses strands whose histories define a path in a suitable two-dimensional configuration space. If the physical history can escape through an additional normal direction while remaining collision-free, the projected crossing sequence need not be invariant.

This leaves two logically distinct possibilities:

- **Projected braid representation:** a source-defined observer projection produces a genuine path in a specified planar configuration space, with the necessary no-collision and endpoint/closure conditions.
- **More general physical interbraid constraint:** the full worldtube geometry restricts admissible configurations, but its invariant may not be an ordinary Artin braid class. It could require a different configuration-space or constrained-homotopy object.

Do not assume these are equivalent. The direct source establishes the physical constraint premise; it does not yet select which of these mathematical realizations is correct.

### Projection/factorization test

The existing Kestrel fiber criterion gives the relevant condition for an observable braid label:

\[
\beta=\bar\beta\circ O
\quad\Longleftrightarrow\quad
O(x)=O(y)\;\Rightarrow\;\beta(x)=\beta(y).
\]

In words: a braid label factors through the observer readout exactly when it is constant on every fiber of that readout. If two physically distinct worldtube histories collapse to the same observer output but carry different candidate braid labels, the label is not determined by that readout.

This is a generic set-map criterion already present in Kestrel PR #873's `KestrelProjectedIncidence` work. It does **not** supply the physical \(O\), define \(\beta\), or prove that the source geometry yields a braid invariant. No new Lean proof or build was run here.
