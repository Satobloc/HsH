## Context / correction status

The naming source positively establishes **UI = Universal Indicatrix** in Nathan Direct wording.

The native construction source materially sharpens what that name refers to. UI is not adequately represented merely by membership in a single hypersphere. Its source construction includes a **relation between two normalized hyperspherical frames/setups, relative rotation, fixed/coincident-point structure, trajectory control, and scaling**.

Accordingly, preserve this formalization guardrail:

> **hypersphere constraint ≠ full Universal Indicatrix**

unless the rest of the generating structure is supplied or the work explicitly declares that it is using a reduced UI model.

Neither source establishes an identity `UI = Δc=0`. A center-coincidence condition may occur inside a representation or reduced constraint system without thereby constituting the entire UI.

The later alias `UI = TX` has separate current-status support in `WORKSPACES/COMMON/CURRENT_HSH_HYPOTHESIS_STATUS_2026-09-14.md`; keep that status evidence distinct from the Nathan Direct naming/construction sources.
