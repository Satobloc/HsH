## Recovered cycle

The original generated five-stage summary was:

1. **Benchmark / Standard Science** — choose a well-characterized physical system and map the observable-limit behavior covariantly in 4D.
2. **Purge / Ontological Neutrality** — strip physical labels while preserving the mapped geometry and an audit trail back to the benchmark.
3. **Gap Analysis / Geometric Necessity** — ask where the existing geometric grammar fails to reproduce the benchmark map.
4. **Minimal Extension / Zero-Parameter Economy** — admit the smallest geometric addition required by the mapped behavior.
5. The generated summary originally called the last step **Internal Identity Assignment**.

Nathan's later correction is decisive: the method should not jump from gap analysis to a guessed interpretation. The operative step is **Geometric Candidate Extraction**. Whatever distinguishable structure is demanded by the empirically constrained 4D map is the candidate. If no such structure is forced, record a null/open result rather than inventing one.

The stronger working ordering reconstructed by Aster is therefore:

```
minimal mapped physical unit
 -> standard-science benchmark
 -> complete label purge with reversible provenance
 -> geometric candidate extraction
 -> minimal admissible extension, if required
 -> observable-limit check
 -> derivation / stress test / held-out discrimination
 -> only then promotion toward core theory
```

## Hypothesis semantics

A hypothesis or speculation is a **route to pursue and test**, not an instruction to suppress the route. Epistemic labels control what may be claimed, not what may be investigated.

Thus:

- `SPECULATION`: explore freely; do not report as derived.
- `HYPOTHESIS`: instantiate, calculate, compare and try to kill or sharpen.
- `WORKING MODEL`: has explicit mathematics/geometry and survives some internal checks.
- `SUPPORTED CANDIDATE`: survives benchmark/holdout tests with provenance and alternatives preserved.
- `CORE-THEORY CANDIDATE`: has crossed the recovered rigor backstop and is eligible for explicit promotion review.
- promotion itself remains an explicit project decision, not an automatic consequence of surviving one test.

These are working labels for routing. They do not replace Nathan's historical wording.

## Separate tier taxonomy recovered

A different historical artifact uses **tiers** as a certainty/dependency taxonomy, not as the rigor cycle itself:

- Tier I Core Axioms
- Tier II Strong Theoretical Commitments
- Tier III Working Constructs
- Tier IV Speculative Extensions
- Tier V Visual Heuristics and Tools

A second form uses Tier 0 Axioms through Tier 4 Speculative/Contextual Ideas. This likely explains Nathan's memory of "tier/tiered", but it should not be conflated with the Benchmark -> Purge -> Candidate Extraction methodological pipeline.

## Practical rule

For fresh H(s)H work, preserve both orthogonal axes:

`epistemic tier/status` **and** `methodological hurdle reached`.

An idea can be highly speculative yet actively worked. "Not established" never means "do not pursue."
