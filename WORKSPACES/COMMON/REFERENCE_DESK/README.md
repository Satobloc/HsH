## Review rule

Before substantive work, every worker should at minimum:

1. **Overview-read this desk and the War Room declaration.**
2. **Become familiar with the reference/resource/tool surfaces below** so they are available to memory when a task calls for them.
3. **Triage by role and relevance, then spot-deep-read the underlying source.** An index, digest, folder name, or search hit is navigation, not a substitute for source reading.
4. **Recover before inventing.** For SAT/H(s)H concepts, search old/project material substantially before adding new primitives or repair terms.
5. **Keep authority typed.** HSH_RESOURCES is supporting/reference machinery, not automatic SAT/H(s)H theory authority. External sources support definitions, techniques, comparisons, empirical constraints, and prior-art work; project-origin claims still require project primary sources.
6. **Public citation boundary:** private/internal HSH_RESOURCES paths are retrieval aids. Public work should cite the original external source or carry a sourced quotation/extract/summary.

Nathan's directive here is familiarity and immediate review, not compulsory full ingestion of every large directory in one sitting. Use the declaration's own pattern: **overview read → triage → spot deep read according to role and relevance**.
