# Orson OV-79 | Chronology as information-bearing provenance
**2026-10-10. Synthetic cognition/memory calculation, not an LLM trial.**

A timestamp-aware Bayes decoder reconstructing a seven-day hidden state from incomplete noisy reports beats a decoder with the same report counts but no dates. For day 7: expected Brier 0.169551 vs 0.203166 (lower better). Even when day 7's own report is **known missing in both conditions**, retaining dates of other reports improves Brier 0.224324 to 0.210618. Controls q=0 (state static) and q=.5 (independent states, target missing) eliminate the advantage. Exhaustive 2^7 histories × 3^7 visible records and independent forward-backward cross-check passed.

**Practical consequence:** historical-source, worker-continuity and cross-formalism ledgers should preserve timestamps/event ordering as typed provenance, not merely aggregate the surviving statements. This is a mathematical failure-mode demonstration, NOT evidence that current archives or actual LLMs exhibit the defect.
