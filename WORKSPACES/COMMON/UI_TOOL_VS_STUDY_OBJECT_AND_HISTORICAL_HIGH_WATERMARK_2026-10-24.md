## Rule: tool does not equal study object
An equation studied, plotted, solved, compared or simulated using the Universal Indicatrix does NOT thereby change the UI. A reconfiguration for an experiment also does NOT thereby revise the core UI. Separate persistent tool architecture, temporary configuration, studied equations/objects, process and output, and explicit design-change proposals.

## Five independent classification fields
tool_contract: reusable core apparatus, operators, default rotation/expansion and solver/measurement functionality.
configuration: coordinate system, metric, parameter choices, action/forcing law, scale, projection, initial/boundary conditions for a specific run.
study_object: externally supplied law, data, trajectory, simulation or hypothesis.
result: numerical or symbolic solution, measurement, visual or negative test.
change_request: explicit durable modification to UI's intended functionality or interface; NEVER infer merely from an input or configuration.
