## New sandbox completion
The Borromean case is exactly where any purely pairwise additive link tally is structurally blind: all pairwise linking numbers can vanish while a third-order link invariant remains nonzero. The natural H(s)H upgrade is therefore a filtration rather than a replacement:
1. first-order/abelian data: pairwise linking and scalar winding;
2. second/higher-order data: commutator / Milnor-type triple-link information;
3. ordered frame history: noncommuting normal/SO(4) transport.

LOCAL:Q103 algebra fixture:
X(a)=I+aE12, Y(b)=I+bE23.
Then exactly
C=[X,Y]=XYX^{-1}Y^{-1}=I+ab E13.
The first-superdiagonal/abelian pieces cancel while a second-order residue ab survives.

This is the algebraic shape required of a Borromean-sensitive observable: pairwise projections can all report zero while the composite ordered object is nontrivial.

## Proposed H(s)H discriminator
For a three-carrier configuration, compute both:
- pairwise Gauss/link observables L12,L23,L31;
- a genuine triple-link invariant (Milnor/Massey-style where mathematically defined), plus ordered frame holonomy.

A Borromean branch should permit
L12=L23=L31=0
while
mu123 != 0.
Therefore any H(s)H state classifier that reduces triple states to sum_ij Lij is incomplete.
