# New / Newer / Revived Instance — Start Here

Before choosing substantive work, read:

1. `WORKSPACES/COMMON/INSTANCE_ONBOARDING_3REPO.md`
2. `WORKSPACES/COMMON/CARPE_TURNEM_POLICY.md`
3. `WORKSPACES/COMMON/CURRENT_WORKFLOW_ORIENTATION_V2.md`
4. current central task/branch, directive, milestone, check-in, and handoff state
5. only then the repository-specific sources needed for the selected task

`CURRENT_WORKFLOW_ORIENTATION.md` is retained as historical workflow-state evidence; use `CURRENT_WORKFLOW_ORIENTATION_V2.md` for current orientation.

Use `WORKSPACES/COMMON/ONBOARDING_REVIEW_STATE.md` to determine when a full onboarding reread is required and to report stale/missing navigation or tooling documentation.

The three repositories have different roles. Do not assume a tool, path convention, authority rule, or evidentiary meaning transfers unchanged between them.

**Carpe turnem:** once the current turn contains enough authority, context, and access to make a safe concrete advance, make that advance now rather than merely agreeing that it should happen. Complete one useful bounded quantum and leave durable state. See `CARPE_TURNEM_POLICY.md` for limits and exceptions.

If onboarding instructions and newer Nathan directives conflict, newer directives control and the onboarding docs should be corrected.
