### A. Tak et al., Findings of EMNLP 2026

*From Process Loss to Assembly Bonus: Human-Grounded Diagnosis of Multi-Agent LLM Collaboration* (ACL Anthology 2026.findings-emnlp.1341; October 2026).

This is a human-grounded comparison, **not a live mixed human-LLM experiment**:

- Human side: 500 DeliData human-only group-chat dialogues, averaging 3.16 participants.
- LLM side: separate three-agent groups using Qwen3-4B/14B/32B and gpt-oss-20b.
- Table 1 sums to 4,800 reported LLM Wason group runs across homogeneous/heterogeneous conditions.
- Additional LLM-only tasks: EAL, ACR and AR-LSAT.

The paper reports stronger majority-following, lower unique-information realization and earlier lock-in in LLM groups. Correct minority signals matter chiefly when publicly re-expressed early and carried to the final answer. Its N=5 comparison did not significantly improve final score over N=3 (0.798 vs 0.789, Mann–Whitney p=.13), and did not remove the coordination bottleneck.

A useful contrast in Table 1: human groups report WAB 63.8%, SAB 18.4%, process loss 47.8%, recovery 27.1%, drift 19.6%; Qwen-14B homogeneous groups report WAB 53.3%, SAB 49.7%, process loss 21.7%, recovery 54.5%, drift 62.0%. The latter is high movement in both corrective and destructive directions, not a stable truth-wins regime.

### B. AgentDelib source audit

Repository: `ala-ntak/AgentDelib`, main commit `1947663fe7329a89a712aca459c6621794ac220b`.

Pinned source blobs:
- facilitator.py: `bd9bf066ad8a9904c02ed728c9c987068d768238`
- prompts.py: `ddff6f7c4f312f6203af124e43ed67129738811a`
- config.py: `999ea374b94316ca6aa6d74489910b6aff9fa88a`
- main.py: `ff530625ac3c2efd49348134bfadf9d9c0b5c08d`

Code-level architecture:
1. `_prepare_observations` builds per-agent observations from one pre-step world state.
2. `step()` computes every active agent's intent from that already-built snapshot before executing any current-step action. Thus a same-step peer message cannot influence another agent's same-step intent.
3. The facilitator selects one highest-priority public message per step; tool actions are then executed for all agents that proposed them.
4. The code constructs private-message intents but unconditionally sets `private_msgs = []` before execution. The private-message execution handler exists, but private messages are inactive in this runtime path.
5. Initial submissions are stored with `visible_to=[agent_id]`; peers do not see them by default. The RevSol intervention explicitly reveals the initial submissions to the group.
6. `compose_messages` supplies only the last 40 visible messages to each agent. The context projection is therefore filtered and bounded, not the complete event history.
7. Separate provider objects are created per agent, but agents may share the same model/backend. Separate calls/client objects do not establish statistical independence.

This is a synchronous, facilitator-arbitrated, single-public-speaker-per-step protocol with potentially multiple tool-state updates. It is not asynchronous peer-to-peer messaging. The private-message path being inactive does not contradict the paper's public-chat protocol; it narrows what the code actually implements.

Small reproducibility discrepancy: `Config` declares initial-phase max 12, while the CLI and README default to 10; group-phase max is 30 in both. The actual CLI runtime uses 10 unless overridden.

The repository README says run logs are generated locally under `logs/`; no experiment trace files surfaced in the inspected repository paths. No root LICENSE file was returned by the checked path, so reuse terms should be confirmed before code reuse.

### C. Real human groups with an LLM facilitator

Parisi et al., *Real-Time Group Dynamics with LLM Facilitation: Evidence from a Charity Allocation Task* (FAccT 2026; Google DeepMind publication dated 2026-06-26).

Two real-time studies, N=879, groups of three, real $7,200 stakes. This is a genuine mixed human-group/LLM-facilitator study, but not a multi-agent peer group.

Reported findings:
- LLM facilitation did not significantly improve consensus.
- Participants preferred facilitated discussion.
- Select charity allocations shifted by up to 5.5 percentage points.
- Neither survey nor transcript measures showed improved participation equity.
- Participants reported greater process trust under conditions where facilitators exerted directional influence.

This supports keeping collective accuracy, consensus, allocation outcomes, participation equity and perceived trust as separate outcomes. Perceived procedural improvement is not evidence of improved equity or neutral facilitation.

### D. Combined experimental taxonomy

The current literature should distinguish:
- multiple humans plus multiple LLM peers (the earlier Chen et al. mixed-group study);
- human-only groups versus separate LLM-only groups (Tak et al.);
- human groups with one LLM facilitator (Parisi et al.);
- one human interacting with multiple role-conditioned LLM agents (Lee & Lee).

These are not interchangeable experimental objects. The new Tak paper is a valuable process comparator, but should not be counted as a mixed human-LLM group experiment.
