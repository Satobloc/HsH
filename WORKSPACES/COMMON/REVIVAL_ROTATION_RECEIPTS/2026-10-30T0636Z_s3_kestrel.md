## New architecture

For a transverse k-dimensional carrier stratum A in M4 and a regular 3D timesheet Sigma:
dim(A intersect Sigma)=k+3-4=k-1.
Thus 1D worldline -> 0D events; 2D worldsheet -> 1D curve; 3D shell -> 2D surface; full 4D finite-core bulk -> 3D volume. The final row is conditional on a full-dimensional carrier; BEDROCK's solid-4D-tube oblique-slice ellipsoid is an idealization, not a universal selection.

A simple contraction J_ws^{mu-nu} partial_nu zeta_Sigma is tangent to the level set by antisymmetry, but it does not restrict support to S intersect Sigma. A sharp-slice candidate requires an explicit intersection/pullback; for a regular immersed 2D sheet X(s,t), the local tangent generator is (partial_t f) partial_s X - (partial_s f) partial_t X, f=zeta_Sigma composed with X. This yields a 1D intersection current in the zero-thickness limit. The worldsheet is not defined by SAT4D's 1D gamma alone.

BEDROCK finite-thickness correction: delta(zeta_Sigma) is only the sharp-sheet limit. A finite-thickness response needs an unspecified, source-derived kernel K_hSigma with declared physical normal coordinate, width, normalization and uncertainty. Keep hSigma distinct from intrinsic core thickness epsilon and coil radius ell_f. No Gaussian/top-hat profile invented. A finite-width kernel weights a 2D worldsheet strip rather than only the 1D sharp intersection; a further projection/coarse-graining is required before calling the result a 3D timesheet response. This addendum is public comment #6516826459 on issue #1089.
