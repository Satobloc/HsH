- the existing Candidate hard gate;
- an `EvidenceGatedFrozenCommonReadout`;

- an explicit source/model/readout binding witness;
- H(s)H and standard model maps and state sets;
- two-sided detector-level separation computed through the same readout carried by the admission object.

The `admittedCandidate` accessor exposes a Candidate only through that complete object. The added `evidenceGatedIntelligibilityTieBreak` accepts two complete admission objects and requires the same declared system, dataset, readout identity and measurement mode. This is an opt-in safe admission API. It does not remove or globally replace the legacy raw-Candidate tie-break in #1487. Downstream production selection must still be routed through this object in a later reviewed integration.
