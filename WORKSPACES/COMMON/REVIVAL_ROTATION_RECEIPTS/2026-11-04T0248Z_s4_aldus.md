### Core findings

The focal preprint, arXiv:2609.07573, is an LLM-only simulated-deliberation study, not a live human-LLM group experiment.

The current public repository snapshot is commit `1b79c5153ac58272fd1e54ab76d8ca4f0545e8c5` (2026-10-13T09:31:55Z). Its current debate and anchoring-grid data/analysis were added after the preprint's 2026-09-07 submission. The current README describes eight Korean policy questions and six model labels; exact identity with the preprint's original tables/sample was not established. No later arXiv revision was verified.

Independent reanalysis matched debate and monologue records by question and seed. Across six model runs, aggregate strict opposite-side flip rates differed by only 0.14–7.61 percentage points, but the persona-level flip-set Jaccard ranged 0.463–0.758 and final persona-room stance disagreement ranged 12.02–30.56%. Qwen is especially diagnostic: debate/monologue flip rates differed by 0.14 pp, while Jaccard was 0.463 and final disagreement 30.56%.

The anchoring-grid probe compared the same debate transcript with a focal persona's own prior turns included versus removed while peer turns remained. Under explicit side cues/opening statements, removing own turns substantially increased opposite-side changes (examples: GPT-4.1-mini chosen/cue 1.4% vs 47.3%; DeepSeek-V4.1 chosen/opening 3.5% vs 52.1%; GPT-6-luna chosen/cue 14.7% vs 65.2%). No-cue controls showed little difference. This is prompt-context sensitivity / own-output anchoring, not human social influence.

The source's `n_changed` counts any endpoint inequality, including neutral or unclassified values. The published report separately counts strict opposite-side flips; neutral endpoints did not occur in the current debate/monologue files, and unclassified endpoints were below 0.5% in affected model runs. The no-transcript re-ask control still produced 4.64–30.28% opposite-side changes, so not all movement can be attributed to peer or self history.

The report defines explicit ordered-message projections: no history, own-only, peer-only and full history. The conditions are not a fully crossed factorial: debate uses randomized order, monologue fixed order and a different generated history, while re-ask does not generate speaking turns. The peer-only excluded probe is the closest within-transcript projection.
