## 3. Lane 00 source-fidelity operation

### Primary source

Hao et al., *MemOps: Benchmarking Lifecycle Memory Operations in Long-Horizon Conversations*, arXiv:2607.12893v1, §§3.1–3.2.

The paper organizes a benchmark instance as `(b,C,O,A)`:

- `b`: background/scenario metadata.
- `C`: evidence conversations.
- `O`: gold typed operation trace.
- `A`: evaluation probes.

The paper describes operation traces through operation type, target object, old/new values, and evidence spans; its abstract additionally names trigger, scope, state transition, and supporting evidence. Five operation families are Remember, Forget, Update, Reflect, and composed TrajectoryOps. Six probe families include OperationTrace, TargetBinding, StateTransition, CandidateDisambiguation, OperationApplication, and StateTrajectory.

### Glossary

| Term | Meaning | Provenance/status |
|---|---|---|
| Evidence conversation | Ordered source dialogue used to ground a benchmark item | Paper-defined |
| Evidence span | Selected source-turn range supporting an operation | Paper-defined |
| Operation trace | Gold sequence of typed memory events | Paper-defined |
| State trajectory | Intermediate and final states across an operation sequence | Paper's evaluation target |
| Endpoint snapshot | Final state after executing a history | Assistant model output |
| Probe | Evaluation question/task over trace or trajectory | Paper-defined |
| Two-slot state space | `Option Nat × Option Nat` | Assistant reconstruction |

### Mapping diagram

The following is an interpretive decomposition, not a set of functions mathematically defined by the paper:

```text
b = background/scenario metadata

C (evidence conversations)
  -- span selection sigma -->
E (selected evidence spans)
  -- trace interpretation/generation iota -->

(s0, O)
  -- execution under transition relation delta -->
```

The paper specifies benchmark objects and a generation/verification procedure, not formal maps `sigma`, `iota`, or `delta`. No one-to-one map, isometry, or physical geometry is established.
