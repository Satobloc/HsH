## 1. Substantive result

Extended the existing Kestrel chain-aware projection-fiber module with a near-fiber stability contract. The prior exact-fiber bound required equal projected inputs. The new candidate permits a measured upper bound `ρ` on projected separation, provided the decoder is pairwise stable on that pair with coefficient `K ≥ 0`.

Let `p : X₀ → Y`, `g : Y → Xₙ`, admissible inputs `x,y`, and exact chain outputs `Fₙ(x), Fₙ(y)`. Assume:

1. `d_Y(p(x),p(y)) ≤ ρ`;
2. `d_Xₙ(g(p(x)),g(p(y))) ≤ K d_Y(p(x),p(y))`;
3. both chain outputs factor through the same `g ∘ p` on the admissible domain, with each endpoint's finite-chain error bounded by `Eₙ`;
4. observed outputs `oₓ,oᵧ` satisfy deterministic endpoint radii `d(oₓ,Fₙ(x)) ≤ ηₓ` and `d(oᵧ,Fₙ(y)) ≤ ηᵧ`.

The intended consequence is:

\[
d(o_x,o_y) \leq \eta_x+\eta_y+2E_n+K\rho.
\]

Thus a held-out pair with observed separation strictly greater than that threshold is incompatible with the declared projection/decoder/chain contract.

**Why this is a real architecture improvement:** exact equality of measured projected inputs is usually an idealization. The `Kρ` term makes imperfect matching explicit and forces decoder sensitivity to become a bounded, independently justified quantity. Without a calibration-frozen `K`, the threshold can be made arbitrarily permissive and the discriminator is not falsifiable.

This is a generic conditional metric-space statement. It does not define a physical projection, detector map, worldtube thickness, twist, contact surface, or SAT-specific observable.
