# Glass Sausage Factory — Voice Routing Guide

**Purpose:** public bridge for site-building instances.  
**Canonical private voice architecture:** `Satobloc/HSH_RESOURCES/PDF_SPECS/NATHAN_VOICE_MODEL/`  
**Site-default standard:** `Nathan_Public_Web_Storytelling_Standard_v8.1.md`  
**Detailed router:** `SITE_VOICE_ROUTER_v1.md`

Nathan directly approved the new public-web model as the Glass Sausage Factory **site-default** on 21 Sep 2026. The model is distilled from Nathan’s verified writing/voice evidence and the accepted origin-story exemplar now published on the site.

## Governing rule

> **Route by function first, location second, surface vibe last.**

The public site should not be flattened into one voice. Use the public-web storytelling model as the human-facing default, then switch locally when another function has priority.

## Routing map

- **Homepage hero, origin story, biography, essays, Substack/newsletter, podcast framing, public conceptual introductions:** Public Web Storytelling.
- **Roadmap, archive orientation, provenance, methodology, state-of-theory summaries, operations, control surfaces:** Nonfiction Communication Standard.
- **Scientist-facing route, technical claims, derivations, predictions, formal mappings, result/limitation prose:** Peer-Review Writing Fingerprint.
- **Explicitly creative, fictional, comic, or high-play passages:** Creative/Informal Reference.
- **Authorship/source attribution:** Voice Identification / Provenance Fingerprint only; do not use it to generate prose.
- **Raw/source-rendered archival material:** no voice rewrite. Preserve source exactly.

## Mixed-page rule

Switch by block rather than averaging incompatible models.

Preferred sequence when a page needs several modes:

**human setup → technical statement → status/limitation → human landing**

Tone must never change claim strength.

## Important page-specific defaults

- **Claims Explorer:** peer-review + nonfiction; public-web only for wrapper copy.
- **Glossary / translation:** nonfiction; peer-review for equivalence/limitation language.
- **Reading Room / archive indexes:** nonfiction wrapper; source itself untouched.
- **History:** nonfiction chronology + public-web transitions; never back-project later theory.
- **Image record:** nonfiction provenance; peer-review for computational figures; public-web intro only.
- **In the news:** nonfiction + peer-review; keep external result, overlap, chronology, and influence evidence separate.
- **Podcast:** public-web framing + nonfiction metadata.
- **Legal/license/citation:** nonfiction, minimal personality.

## Canonical style test

Before publishing a generated block, ask:

1. Would Nathan recognize the intended meaning as his?
2. Would a competent stranger know what kind of statement this is?
3. Did the prose preserve the object rather than polishing it into something else?

If not, reroute the block.

## One-line Sites instruction

> **Use the Public Web Storytelling standard as the human-facing default, but route claim-heavy text to Peer Review, state/provenance/operations text to Nonfiction, strongly creative material to Creative/Informal, and never rewrite primary source material; switch locally by block function rather than forcing one voice across an entire page.**
