## 3. Substantive architecture improvement

Created a **two-axis identifiability and model-discrimination contract** as an additive refinement to existing issues #1301, #1385, and #1735.

The existing `UNIDENTIFIABLE` status risks conflating four different things:
1. exact source-to-observable map non-injectivity;
2. local first-order geometry effects absorbed by nuisance directions;
3. structural separation that the actual finite/noisy dataset cannot resolve;
4. H0/H1 predictions that overlap at the declared instrument resolution.

These have different causes and different remedies. The new contract keeps two records separate:

### Axis A: identifiability within a model

- `MAP_INCOMPLETE`
- `STRUCTURAL_NONIDENTIFIABILITY`
- `LOCAL_RANK_DEFICIENT`
- `PRACTICAL_UNIDENTIFIABILITY`
- `IDENTIFIABLE_AT_DECLARED_SCOPE`

Each status carries the domain, gauge/quotient convention, exact observation-map version, and evidence needed for the next action.

### Axis B: discrimination between H0 and H1

- `PREDICTION_NOT_FORMED`
- `UNSCORABLE`
- `NONDISCRIMINATING_AT_DECLARED_RESOLUTION`
- `CALIBRATION_ONLY_SEPARATION`
- `HOLDOUT_DISCRIMINATED`
- `H1_REJECTED` / `H0_REJECTED`
- `JOINT_MISFIT`

The key non-implications are explicit:
- H1 parameter identifiability does not imply H0/H1 discrimination.
- A local separating direction does not imply practical detection.
- Calibration fit does not imply holdout prediction.
- Failure to detect a difference does not establish exact equivalence.
- A model passing while the comparator fails is evidence about those frozen implementations, not proof that H(s)H is true.

The existing P2 E-D-F-R admission structure is unchanged. The proposal adds typed subrecords within its existing map/identifiability and paired-freeze/holdout legs; it does not create a competing gate or alter ownership.
