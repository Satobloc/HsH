## Operation

After Runs 90–92 closed the current manual-external identity scope to one production record, rotated to a fresh Viewer QA target: whether the documented reversible curation layer applies uniformly to external Viewer conversations as the current documentation appears to imply.

## Finding

Whole-conversation hiding is source-location independent: `apply_curation()` drops a matched item before any source file is opened.

Partial curation is different. For a rule containing `omit_ranges` or `only_ranges`, `apply_curation()` calls `write_curated_copy()`. That function constructs `Path(item["path"])`, requires that path to exist in the **HsH checkout**, and opens it locally. External catalog records, however, are deliberately canonical pointers to another repository; the Viewer README says unique GLASS conversations are not copied into HsH and are fetched from their canonical repository only when selected.

Therefore a partial-curation rule targeting a canonical external conversation whose source exists only in GLASS cannot be materialized by the current builder: the local `Path(item["path"])` existence check will fail. Whole-conversation hiding should still work because it does not invoke `write_curated_copy()`.

Current `CURATION.json` has no rules, so this is a **latent capability/documentation mismatch**, not evidence of a current production build failure. No external partial-curation production case was observed in this bite.

## What this establishes / does not establish

Establishes under current inspected code:
- local HsH partial curation reads the source from the HsH checkout;
- external records are appended with `external=True` but partial-curation source resolution does not branch on repository/source URL;
- a canonical external-only source path is not locally resolvable by that code path;
- whole-conversation hiding does not share this dependency.

Does **not** establish:
- that any currently published conversation is wrongly curated;
- that a current build is failing (curation rules are presently empty);
- that external sources cannot be hidden wholesale;
- that source archives are altered by curation;
- anything about theory correctness or source authority.
