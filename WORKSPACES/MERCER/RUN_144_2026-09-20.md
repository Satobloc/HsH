## Change
Updated `tools/build_mersearch_index.py` at commit `88ba6a8db73d7f249c9b9da5c3f7bf6d19ceed30`.

The builder now:
- stamps `max_bytes` and exclusion configuration into the generation manifest;
- reuses a current generation only when schema, builder version, max-byte limit, and exclusion set match;
- deliberately forces one full baseline build when an older manifest lacks the new compatibility stamp;
- clones the prior immutable SQLite generation rather than mutating it;
- hashes every permitted source and reuses unchanged indexed records by SHA-256 identity;
- removes deleted/changed source rows and corresponding FTS rows only in the unpublished clone;
- reparses/reindexes only new or changed source files;
- refreshes unchanged source size/mtime metadata without treating mtime as content identity;
- records reused/added/changed/removed source counts, parsed-record count, bytes hashed, and parent generation in manifest metadata;
- preserves atomic `CURRENT.json` publication and the intentional pre-publication failure hook.
