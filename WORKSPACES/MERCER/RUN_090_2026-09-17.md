## Finding

The Viewer external-source pipeline currently carries two different source-identity strengths.

The manually registered Srena entry records `source_repository`, `source_branch`, source path, raw/GitHub URLs, parser/format, and a provenance note, but it does **not** record a content hash or immutable repository commit/blob identity. The generated merged external-conversation file preserves that manual record without adding such an immutable identity field.

By contrast, structurally discovered public cross-repo entries in `CONVERSATION_VIEWER/data/discovered_external_conversations.json` record `source_repository`, `source_path`, and `source_sha256` in addition to URLs and discovery method.

A direct repository fetch confirms the currently addressed canonical Srena source exists at `Satobloc/SAT_THEORY_ARCHIVE_2023-25/SRENA SAT2.txt`; the current Git blob SHA returned by GitHub is `fe01fc85b1874c1573843724f035ee292fd48961`. This SHA is **not presently carried in the manual registration or generated merged external record**.

## What this establishes

This is a **provenance-observability asymmetry**, not evidence that the Srena registration points to the wrong source. Repository + branch + path currently resolve to a real canonical source, but `main` is mutable, so the manual registration alone does not freeze which source bytes were inspected when the Viewer record was generated. Discovered entries have stronger content-level reproducibility through `source_sha256`.

This does not establish that every external registration must use the same schema, that the current Srena bytes have changed, that Viewer parsing is wrong, or that any conversation/theory content is authoritative or correct.

## Durable result / next cursor

Recorded the asymmetry without editing the shared Viewer schema or registration. Best next bounded operation: inspect the external-discovery generator/workflow to determine whether manual registrations are intentionally exempt from content-hash enrichment or whether this is a small reproducibility gap that can be repaired at generation time without changing source disposition.
