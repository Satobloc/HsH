Therefore, represent two independent axes:

**Manuscript/editorial:** draft → reviewed → originator disposition → accepted R1.

**Presentation:** source pinned → feed bound → derivative built → deployed → live readback → accepted.

For each route, the acceptance record should bind:
paper ID; editorial state; source path/format/blob/commit; feed blob and entry; renderer ID/version/configuration digest; dependency-lock digest; derivative kind and SHA-256; site build ID/version and deployment time; live route; readback time/response digest; screenshot digest; browser version; viewport/zoom matrix; per-check evidence; reviewer; final status.
