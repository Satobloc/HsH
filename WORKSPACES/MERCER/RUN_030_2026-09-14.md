## Findings

### Reliable bounded machine substrate

- Current superset comparator is suitable for strict message/payload subset-candidate detection because it hashes the entire `content` object plus typed message fields and never mutates source.
- Conversation date-prefix tooling is suitable for deterministic rename planning because it defaults to dry-run, emits an audit manifest, and globally blocks mutation on collision.
- Autotag → Nathan Direct → Stage-2 count arithmetic is suitable as a structural integrity invariant, not semantic authority.
- Viewer catalog is suitable for navigation/candidate selection only when its source-state freshness is checked.

### Machinery requiring point-of-use checks

`extract_raw_window.py` still serializes only `content.parts`/nested text. It therefore should not be treated as a complete-content serializer for arbitrary ChatGPT export content shapes. This is materially related to the older `MORROW-SOURCE-001` lesson, although ordinary user-text recovery can still be valid when the source messages actually use `parts`.

### Observed failure modes consolidated

1. partial content-shape equality checks;
2. generated navigation path drift;
3. stale generated state mistaken for current source state;
4. source-driven corpus-count changes mistaken for indexing loss;
5. retrieval-negative/proximity metadata overread as provenance;
6. path-normalization collision causing global downstream blocking.

### Infrastructure conclusion

A cross-repo source-integrity layer can mostly compose existing machinery. The missing component is a thin inventory/join/validation surface that records repository/path/blob SHA, stable IDs, source class, derived-parent pointers, generator/source-state markers, parse/count status, and provenance class, then reports discrepancies. A separate parser stack is not warranted.

### Sampling conclusion

Use stratified source-to-derived round-trip sampling plus deterministic rotating coverage, with permanent regression specimens for every observed failure mode. At minimum include ordinary text, nonstandard content shapes, duplicate/superset families, rename candidates, external Viewer records, PDF/extraction pairs, and generated index/package records.

### Continuity-role boundary

Mercer can safely inherit deterministic identity/path/UUID/checksum/index reconciliation work from Morrow. Branch-equivalence judgments, conversation-family causality, routing/crosstalk interpretation, and context-significance decisions should remain with a continuity specialist or explicit contextual review.
