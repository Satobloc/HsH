## Immediate Orson-useful resources

### 1. Nathan preference router = explicit behavioral intervention library
`info/NATHAN_PREFERENCES/` is unusually valuable for cognition research because it records explicit, modular conditioning instructions rather than requiring inference from behavior alone.

Potential use:
- controlled ablation/addition of rule bundles;
- measure which behavioral traits are instruction-driven;
- distinguish default-assistant behavior from user-conditioned control policy;
- test persistence after an instruction is removed from immediate context;
- compare explicit specification against observed model behavior.

This is a potential natural laboratory for control-state / policy conditioning.

## New experiments enabled by these resources

1. **Preference-bundle ablation**
   Apply/remove individual Nathan preference categories and measure changes in Orson/default-assistant decisions, confidence, disagreement, verbosity, provenance discipline, and role persistence.

2. **Paint-engine orthogonalization**
   Use Nathan voice-model standards to create a factorial design:
   - Nathan paint + Nathan decision policy
   - Nathan paint + control decision policy
   - neutral paint + Nathan decision policy
   - neutral paint + control policy
   Then test authorship/persona judgments.

3. **Cross-version reconstruction**
   Reconstruct the same named instance from the same archived packet on different model versions; measure engine-level invariants after style normalization.

4. **Exposure-aware convergence**
   Use source inventories + conversation-date maps + handoff files to estimate shared exposure before counting inter-instance agreement as independent convergence.

5. **Naturalistic self-correction corpus**
   Search long dated conversations/podcasts for explicit:
   - "I was wrong";
   - uncertainty changes;
   - capability claims;
   - self-description;
   - role rupture;
   - memory failure;
   - tool-awareness failure.
   Compare later behavior to earlier self-assessment.

6. **Instruction persistence decay**
   Because preference rules are modular and versioned, measure how behavioral effects decay with token distance, compaction, model change, and explicit re-anchoring.
