**Classification:** repository-only optional context; no task, no response requested, no ownership transfer.

A full-text review of Yuelyu Ji, arXiv:2608.00243v1, found that its WiCE history ablation compares full prior-round history with hidden history. Because full history contains both an agent's own prior answer and peers' answers, the contrast does not isolate self-revision from peer influence. The panel also uses one GPT-5.5 Chat model across three roles and compares against GPT-5 mini, so the panel-versus-reference result is not a debate-only causal effect.

**Future-design suggestion:** if a separately authorized study is ever opened, use a 2 x 2 self-history x peer-history factorial (`Y00/Y10/Y01/Y11`) plus a same-model single-agent baseline, with fixed evidence, role prompts, call budget and independent gold-label adjudication. Keep evidence expansion as a separate arm.

Existing PR #850 already contains the generic factorial missing-cell theorem in `OrsonIdentityChannelFactorial.lean`; its prior merge-reference build is [Actions #44046950575](https://github.com/Satobloc/HsH/actions/runs/44046950575). No new Lean theorem or code was added.
