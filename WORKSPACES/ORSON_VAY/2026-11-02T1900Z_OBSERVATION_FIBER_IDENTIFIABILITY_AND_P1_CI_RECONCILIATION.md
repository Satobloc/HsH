## 3. Glossary

| Term | Stable meaning in this crosswalk |
|---|---|
| Latent state / mechanism (X) | The underlying history, mechanism, or model state not fully present in the record. |
| Observation map (O:X\to Y) | The operation that turns latent states into recorded observations, distributions, or summaries. |
| Fiber (O^{-1}(y)) | The set of latent states that produce the same observable record (y). |
| Target (T:X\to Z) | The property one wants to recover: mechanism identity, a past state, semantic correctness, or causal effect. |
| Decoder (D:Y\to Z) | A rule attempting to recover the target using only the observation. |

| Memory summary | A lossy map from a full temporal history to a compressed record. |
| Realized influence | A receiver-side change attributable to an exposure under an identified comparison; distinct from mere exposure opportunity. |

## 5. General observation-fiber criterion (assistant reconstruction; not yet Lean-formalized)

Let (O:X\to Y) be an observation map and (T:X\to Z) a target.

**Necessary condition.** If a decoder (D:Y\to Z) exists with (T=D\circ O), then:

[
O(x)=O(x')\implies T(x)=T(x').
]

Proof: (T(x)=D(O(x))=D(O(x'))=T(x')).

**Sufficient condition.** If (O) is surjective and (T) is constant on every fiber of (O), then a decoder (D) exists. Choose a representative (s(y)\in O^{-1}(y)) for each (y), and define (D(y)=T(s(y))). Equivalently, an explicit section (s:Y\to X) with (O\circ s=\mathrm{id}_Y) supplies the decoder (D=T\circ s). Without surjectivity, the decoder is naturally defined on (\mathrm{range}(O)), or an explicit default value is required outside that range.

This is a standard factorization/identifiability criterion reconstructed to unify OV-56 and OV-69. It is **not** a Nathan Direct equation, not a physical-geometric claim, and not yet encoded or compiled in Lean.
