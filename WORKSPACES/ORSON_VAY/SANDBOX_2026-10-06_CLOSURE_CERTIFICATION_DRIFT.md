## Orson cognition hypothesis: Closure Certification Drift
Define an evidence tier E for each claim:
0 = asserted
1 = formula written
2 = derivation shown
3 = numerically reproduced from stated inputs
4 = independently cross-checked / empirically supported

Define language-certainty tier L:
0 = conjectural
1 = plausible
2 = coherent/consistent
3 = closed/verified
4 = exact/proven/complete

Define over-certification:
O = max(0, L - E).

The NotebookLM sequence is a natural longitudinal test because the same claim is repeatedly re-rated as documents are added: fatal gap → apparently resolved → still numerically open → later declared closed. Test whether certainty tracks actual new derivational content or merely source-local rhetoric.
