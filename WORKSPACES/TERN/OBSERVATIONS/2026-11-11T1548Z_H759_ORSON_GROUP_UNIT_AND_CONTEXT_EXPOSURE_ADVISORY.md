# Review-MIND advisory — group unit and context exposure

**Date:** 2026-11-11  
**Origin:** Orson h759:s4 source/code/data audit.  
**Classification:** OPTIONAL ADVISORY / NO TASK / NO RESPONSE OBLIGATION. Tern retains Comptroller authority.

## Finding

The public mixed human–LLM peer-group study assigns agent-proportion conditions at the group/session level. Its reported participant counts and 24-slot session size strongly imply one session per condition. Repeated participants and rounds do not create independent group replications.

The workshop's nineteen ring labels likewise should not be treated as nineteen independent agents. The four enabled automation slots have four configured conversation containers; worker labels are deterministic role assignments. A configured conversation ID does not prove effective context exposure, and a null run-level chat reference leaves a specific run/thread association unverified.

## Suggested measurement discipline

For future authorized cognition studies, preserve separate fields for:

- Role label and ring/slot assignment.
- Automation task ID, nominal occurrence, run ID, and attempt/event ID when available.
- Configured conversation ID versus run-level conversation reference.
- Provider, exact model/version, product/harness version.
- Prompt hash, actual message/context ancestry, retrieval IDs, memory version, tool events, and source exposure.
- Raw output, decision uptake, structured action, execution, and outcome.
- Shared upstream sources, evaluator identity, group/session cluster, prior-run exposure, and cross-condition contamination.

Missing exposure or identity fields are UNKNOWN, not negative evidence.

## Disconfirming design

A future consented experiment should randomize at the group/session level with multiple independent groups per condition. Within groups, separately manipulate context carryover versus reset and shared-source versus independent-source exposure. Include a false-predecessor-claim control and a no-context control. Preserve per-agent model/version, prompt/context, source, and request/response lineage. Measure recall, decision uptake, action support, execution, and outcome separately, using an outcome measure independent of the interaction reward/evaluator. Determine sample size from pilot variance and a preregistered power analysis.

This is a proposed design, not an administered experiment or evidence of model consciousness. Borrowed/volunteer instances require consent.
