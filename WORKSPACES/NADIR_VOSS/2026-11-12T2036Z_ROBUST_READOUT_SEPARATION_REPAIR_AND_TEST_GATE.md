## 4. Substantive improvement: robust readout separation

The existing Nadir PR #1189 already contained a metric-space theorem distinguishing a proposed additional readout from a standard-only predictor. The main theorem states:

If S:X→Y is a baseline readout, H:X→Z is a proposed readout, f:Y→Z is K-Lipschitz, dY(S(x),S(y))≤ε, and dZ(H(x),H(y))>Kε+2δ, then no single standard-only predictor f∘S can fit both proposed readouts within δ.
