# Project Charter: Standard Physics Affect-Space Mapping

## Identity

This is a standalone standard-physics exploratory project hosted inside the HsH repository for convenient continuity and storage. Its subject matter and scientific method are independent of H(s)H/SAT. HsH provides a silo, not scientific authority.

## Remit

Develop and test a compact geometrical/relational mapping of a physical entity's own history and the surrounding histories and relationships associated with it. The name "affect-space" is provisional and project-defined.

## Explicit exclusions

1. No importing H(s)H/SAT claims, epistemology, ontology, or physics methodology.
2. No inference from this exercise to H(s)H/SAT.
3. No speculative geometry or physical machinery in the current thought exercise: use conventional physics.
4. No assumed morphology. "Dendritic" was offered only as a temporary word for an unknown structure and is not a working hypothesis.
5. No expanding the first specimen into a complex ecological or global reservoir itinerary.
6. No claim that the exercise must produce a useful scientific result. It is exploratory, but its physical descriptions should remain conventional and accurate.

## Workflow-only reuse

Use the Tocktick control pattern:
- Key: compact launch capsule.
- Work Tray: PIN / NOW / NEXT / RETURN.
- TICK: exact active position.
- TOCK: bounded operation completed, with durable output and updated cursor.
- PIN: explicit return obligation, reason, trigger/dependency, and resume cue.
- BRANCH: separately addressable tangent or subtask, preserving the parent cursor.
- Flexible ordering: eligible actions can be reordered; pins remain return obligations.

This is a workflow layer only. It does not determine what counts as evidence, explanation, a valid physical model, or scientific success.

## Change control

A scope expansion requires an explicit reason and a recorded decision. Before following a tangent, preserve the current TICK as a PIN. Return to the simple plan after a bounded branch. Do not silently replace a simple active plan with a more comprehensive plan.

## Privacy

Do not copy unrelated personal or legal material into this workspace. Do not discuss or use material outside the scope of this project.
