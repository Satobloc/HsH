# Standard Physics Side Project: Affect-Space Mapping

**Status:** Active, small-scope exploratory project  
**Host:** HsH repository, in a dedicated silo  
**Scientific framework:** Conventional/standard physics for this project  
**Relationship to HsH:** Hosted by HsH; intellectually and methodologically distinct from H(s)H/SAT. The repository is an organizational host, not a source of physical premises or an endorsement of HsH scientific claims.

## Purpose

Explore whether and how the history and relationships associated with a selected physical entity can be mapped geometrically. The working term is **affect-space**. It is a project-defined term, not assumed to be an established physics construct.

The initial exercise is deliberately simple: choose a bounded entity/history, map its own procession, then expand the surrounding history and relationships only as needed. Do not let a richer or more complete alternative displace the current simple plan without an explicit decision.

## Scope and separation

- Use conventional physics, established physical quantities, standard spacetime concepts, and ordinary scientific sources for this exercise.
- Do not import H(s)H/SAT epistemic, ontological, physical, or scientific methodologies as premises, criteria, or interpretive frameworks.
- Do not treat this project as evidence for, a test of, or an extension of H(s)H/SAT.
- Reuse only the lightweight workflow/navigation mechanism called Tocktick: compact Key, PIN/NOW/NEXT/RETURN, bounded Ticks/Tocks, branch-and-return, durable cursors, and flexible operation ordering.
- Workflow machinery is not scientific methodology. It governs how work is resumed and organized, not how physical claims are justified.
- The project may use unconventional tools or hypotheses in a separate future scientific context, but this particular thought exercise uses conventional physics.
- Do not assume a tree, dendrite, network, continuity, convergence, symmetry, or any other morphology before mapping. Such terms may be placeholders only.
- Distinguish the entity's own procession from the broader field of interactions, antecedents, and consequences considered for affect-space.
- Keep the first specimen simple. Exclude biosphere passage and a complete carbon-cycle itinerary unless explicitly reselected.

## Current conceptual vocabulary

- **Specimen:** the selected physical entity or system.
- **Beginning / end:** selected boundary events that define the specimen's tracked procession.
- **Procession / path:** the history of the tracked entity between those boundaries.
- **Affect-space:** the wider set of relevant relationships, antecedents, interactions, and consequences examined around the procession. Its formal definition remains open.
- **Segment:** a useful partition of a history for mapping. Segment boundaries must be explicit and may differ for different component histories.
- **Morphology:** the structure discovered after mapping, not a shape assumed in advance.

## Method of work

1. Keep the current plan visible in the Tocktick Work Tray.
2. Select one bounded operation.
3. State its scope, expected durable output, stop condition, and return cursor.
4. Perform the operation using conventional physics for this project.
5. Record a Tock only when the output is durable and the next cursor is known.
6. Preserve suspended work as a PIN with its reason and exact resume cue.
7. Reconsider the plan only when evidence or a clearly stated user decision warrants it.

## Current status

The initial carbon-14 candidate led to an unwanted expansion into the full carbon cycle and population-average birth/death distributions. That branch was explicitly closed. The current specimen is **one representative chondrule**, traced from its chondrule-forming heating/melting episode through cooling and disk transport to incorporation into a small, primitive, undifferentiated planetesimal. See [SPECIMEN.md](SPECIMEN.md). The project is now defining the two boundary events; it does not assume a unique individual trajectory or a detailed heating mechanism.
