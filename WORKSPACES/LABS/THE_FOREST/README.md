## Hard premise

This lab takes the strong form of Nathan's information claim as controlling:

> Information about an actual thing cannot exist without a realized physical dependency/ancestry connecting that thing (or a physical trace generated by it) to the record.

Photographs, words, bits, ink, sound, neural states, mathematical inputs, and arbitrary encodings remain physical realizations. Arbitrary encoding changes the map between carrier state and meaning; it does not make the carrier or transmission nonphysical.

This is intentionally stronger than the earlier assistant paraphrase that allowed a merely “empirical anchor.” That weaker formulation is rejected for this lab.

## SAT-specific foundational wager

Nathan further states that SAT treats apparent nonlocality as physically transmitted in a time-perpendicular direction along worldtubes. This is a foundational SAT assumption: if it is wrong and no closely related mechanism can do the required work, SAT is likely a nonstarter.

The lab therefore treats “what counts as local?” as a geometric question. Ordinary projected spatial locality and native worldtube adjacency may differ, but there must still be a physical path.
