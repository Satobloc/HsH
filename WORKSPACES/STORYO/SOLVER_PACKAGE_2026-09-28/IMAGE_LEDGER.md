## Current interpretation rule

Do not choose a winding density because it looks better. Compute the physical/model ratio first. If a 100:1 or 200:1 object becomes visually unresolved, preserve the ratio and change only the documented observation/display map (magnification, axial/time expansion, unwrapped view, or increased sample density).

## Failure preservation

Rejected visual treatments remain in the derivation record because they document exactly which representation choices were identified as misleading or unnecessarily decorative.
