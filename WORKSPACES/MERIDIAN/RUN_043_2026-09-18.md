## Result

Let `Q(s) ∈ SO(3)` be a differentiable relative-frame history. Its intrinsic first-order rotational rate is

`Ω(s) = Q'(s) Q(s)^{-1} ∈ so(3)`

(or the body-frame convention `Q(s)^{-1}Q'(s)`; the convention must be declared). The skew matrix `Ω` has an axial vector `ω(s)` once orientation and coordinates are fixed.

This is the maximal rate information available from `Q(s)` at first derivative order. It does **not** by itself identify SAT atlas variables such as a phase-rate ratio `ν`, relative phase `Δφ`, or chirality `χ`. Those become recoverable only after an additional sourced/declared **phase embedding** specifies which one-parameter rotational degree of freedom in `Q` represents the relevant phase and what the reference phase/parameter is.

### Conditional recovery budget

If a declared embedding supplies an oriented phase generator/axis `J` and reference parameter `s` is itself the denominator phase (or its rate is separately known), then the signed phase rate can be read from the component of `Ω` along `J`. Under that extra convention, a rate ratio analogous to `ν` may be recoverable from `Q'Q^{-1}`. Without that embedding/reference-rate declaration, `Ω` is merely angular velocity in the relative frame and cannot uniquely be called `ν`.

`Δφ` is an integration/initial-condition quantity. A derivative history alone cannot determine its additive phase origin. It can be recovered from `Q(s0)` only if the phase embedding is invertible on the relevant subspace and a phase-zero/gauge convention is fixed. Thus `Q(s)` plus derivatives is insufficient if the representation admits frame/gauge changes that alter the phase coordinate while preserving the represented geometry.

`χ` is likewise not generically encoded by membership in `SO(3)`: every `Q` is orientation-preserving. A signed winding can encode handedness only after choosing an oriented axis/reference frame and establishing that the sign of that winding is the atlas chirality variable. A mirror-related/chiral label that is external to the relative-frame path requires an independent discrete channel.

Finite-core thickness `a/D` is not recoverable from a center/frame similarity history `(Δc(s), σ(s), Q(s))` unless the radii/scale variables have explicitly been defined to contain both `a` and `D` separately. A single scale ratio cannot generically invert to two independent length scales. It therefore remains an independent finite-core channel under the present bare representation.

## Minimal enriched-state candidate

The smallest **conditional** enriched representation worth benchmarking is therefore

`H*(s) = (Δc(s), σ(s), Q(s); phase-embedding/gauge metadata; core channel)`.

If the phase embedding is fixed and invertible, `Q(s0)` can carry phase offset and `Q'Q^{-1}` can carry signed phase rate. If it is not, explicit `(ν, Δφ, χ)` channels remain necessary. `a/D` remains explicit unless a sourced map into the similarity variables is supplied.

This sharpens Run 042: it would be premature to say that simply adding `dQ/ds` closes the information loss. The derivative provides rotational-rate data; the missing mathematical object is the map from that rotational-rate data to the SAT phase/chirality coordinates.

A legitimate round-trip test should therefore vary frame gauge/parameterization while holding represented geometry fixed and ask whether the decoded `(ν, Δφ, χ)` is invariant. If decoding changes under admissible gauge/reparameterization, the decoder is representation-dependent and cannot yet establish lossless equivalence.
