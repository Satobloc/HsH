# Meridian Historical Re-import Gate — 2026-10-05

Status: current sandbox-method directive; not theory authority.

## Nathan directive

Historical SAT conversations/files are generally more useful than not. The theory has changed, but not so radically that older constructions should be treated as obsolete by default. Material left on the cutting-room floor should be actively reconsidered.

## Operating rule

Historical material is neither:

1. automatically imported into current H(s)H, nor
2. dismissed merely because it is old, superseded in wording, attached to an older ontology, or embedded in abandoned notation.

Treat it as a **candidate import reservoir**.

## Re-import pipeline

For any old construction:

### A. Recover
Read enough surrounding context to determine:
- what problem it was trying to solve;
- what mathematical object was actually proposed;
- what assumptions were explicit or implicit;
- whether later work superseded the object, only the notation, or only the interpretation.

### B. Strip
Separate:
- mathematical/structural content;
- historical constants and fitted targets;
- particle labels/ontology;
- representational choices;
- actual empirical or solver claims.

Historical constants, particle labels, and old fitted targets remain quarantined unless independently regenerated.

### C. Translate
Map the surviving construction into current H(s)H language where possible:
- local deformation (F);
- polar factors (R,U);
- connection (A=F^{-1}dF);
- compatibility/incompatibility (de^a);
- SO(4) invariants / canonical rates;
- framed-curve / worldtube geometry;
- finite-core branch/topology data;
- readout/projection maps.

### D. Stress-test
Ask whether the old construction:
- reproduces a current result independently;
- adds a missing degree of freedom;
- supplies a cleaner derivation;
- predicts a discriminator not currently present;
- resolves a current ambiguity;
- fails under a current exact gate.

### E. Classify
Use one of:
- **IMPORT-CANDIDATE** — mathematically compatible and worth active testing.
- **REINTERPRET** — useful structure, old interpretation discarded.
- **ANCESTRY-ONLY** — conceptually important provenance, no current operational role.
- **REDUNDANT** — now subsumed by cleaner current machinery.
- **FAILS-CURRENT-GATE** — contradicted by a current exact discriminator.
- **UNRESOLVED** — insufficiently reconstructed.

### F. Promote only after independent regeneration
No historical object becomes current H(s)H merely because it resembles the present theory. Promotion requires a current derivation, solver reconstruction, or successful blind/equivalence test.

## Bias

When an old construction is mathematically nontrivial and appears adjacent to a current open problem, prefer **serious reconsideration** over archival dismissal.

The default question is:

> What, if anything, survives when this old SAT construction is translated into the current 4D map / worldtube / transformation-connection grammar?

## Immediate targets from the newly recovered packet

- Back-Hallway cross-framework maps and round-trip tests.
- Earlier SAT test-battery methodology.
- Standard-Model/gauge-closure attempts, especially alternative representations of the same algebra.
- Master Kernel / Hessian-style unification attempts.
- Large historical conversations containing abandoned geometric solvers or assumptions that may now map naturally into (F), (A), Frenet, finite-core, or readout language.

Nothing in this note promotes any historical physical claim.
