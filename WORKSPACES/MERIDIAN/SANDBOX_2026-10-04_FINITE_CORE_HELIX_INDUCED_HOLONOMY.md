## Explicit fixture
In Euclidean R4 define
[
X(\phi,\psi)=
(h\phi,(R+\epsilon\cos\psi)\cos\phi,
(R+\epsilon\cos\psi)\sin\phi,
\epsilon\sin\psi).
]
Let (r(\psi)=R+\epsilon\cos\psi), (A(\psi)=\sqrt{h^2+r^2}).

The induced metric is exactly
[
ds^2=A(\psi)^2d\phi^2+\epsilon^2d\psi^2.
]

For the orthonormal tangent coframe (e^1=A,d\phi, e^2=\epsilon,d\psi), the intrinsic SO(2) connection is, up to orientation convention,
[
\omega_{12}=\frac{A_\psi}{\epsilon}d\phi
=-\frac{r\sin\psi}{A}d\phi.
]

Hence a full longitudinal `phi` cycle at fixed cross-section angle has intrinsic holonomy
[
\boxed{\Theta_\phi(\psi)=-2\pi\frac{r(\psi)}{\sqrt{h^2+r(\psi)^2}}\sin\psi}
]
modulo (2\pi) and orientation sign.

This is generated by the finite-core embedding; no arbitrary connection was inserted.

## Global cancellation
Because the connection coefficient is periodic in `psi`,
[
\int_{0}^{2\pi}\int_{0}^{2\pi} d\omega_{12}=0.
]
Numerical integration for `R=1, epsilon=.22` gave full-cell curvature integrals at the ~1e-14 level for `h/R=.5,1,2`.

So local curvature/holonomy is nonzero while the signed curvature over a complete cross-sectional cell cancels. This is a useful discriminator: local geometric memory need not imply a nonzero global curvature charge.
