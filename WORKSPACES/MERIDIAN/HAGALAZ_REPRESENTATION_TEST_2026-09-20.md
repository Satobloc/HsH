## Important distinction confirmed

The center-displacement coordinate and affine-similarity translation coordinate are different objects.

For a similarity map

\[
T_{ij}(x)=\sigma_{ij}Q_{ij}x+b_{ij},
\]

that sends center \(c_i\) to center \(c_j\),

\[
b_{ij}=c_j-\sigma_{ij}Q_{ij}c_i.
\]

Direct center displacement composes additively:

\[
\Delta c_{13}=\Delta c_{12}+\Delta c_{23}.
\]

By contrast, affine translation composes as

\[
b_{13}=\sigma_{23}Q_{23}b_{12}+b_{23},
\]

when \(T_{23}\circ T_{12}\) is used. The numerical residual for that law was `7.38e-15`. Therefore a future Hagalaz implementation must type these coordinates separately rather than calling both simply “translation.”

## Frame behavior

With frames stored in a common ambient basis, a global ambient rotation \(R\) sends \(F_i\mapsto RF_i\), hence

\[
Q_{ij}\mapsto RQ_{ij}R^{-1}.
\]

So the matrix entries of \(Q_{ij}\) are not strictly invariant under global ambient rotation; they transform by conjugation. Conjugacy invariants (for example eigenvalue/rotation-plane data, when appropriately typed) are candidates for basis-independent descriptors. A co-rotating storage convention could instead make the recorded relative matrix numerically unchanged, but that is a representation convention and should be declared explicitly.
