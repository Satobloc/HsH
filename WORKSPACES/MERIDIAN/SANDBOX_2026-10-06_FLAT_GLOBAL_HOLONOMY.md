## LOCAL construction

Work on the punctured plane `M = R^2 \ {0}` and embed one SO(2) subgroup in SO(4), generated by `J_01`. Use LOCAL notation

```math
A = k\,d\phi\,J_{01}.
```

For `r>0`, `d(d\phi)=0`, and because the connection occupies one commuting generator,

```math
F=dA+A\wedge A=0
```

everywhere on the punctured domain.

For a closed loop `gamma` with winding number `n` around the puncture,

```math
\oint_\gamma d\phi = 2\pi n,
```

so

```math
U_\gamma = \exp(2\pi k n J_{01}).
```

Thus local curvature is identically zero while global holonomy can be nonidentity.

1. **local curvature gate** — shrinking contractible plaquettes recover `F`;
2. **global topology gate** — noncontractible loop classes can carry holonomy even when `F=0`.

Therefore `F=0` must be typed as `locally_flat`, not `holonomy_trivial`.

## Failure conditions

- If the domain includes the puncture without singular/patch data, the connection is not smooth there and the fixture is invalid.
- Contractible loops away from the puncture must return identity.
- Changing radius at fixed winding must not change the result.
- Reversing winding must invert the holonomy.
- A global SO(4) basis change may conjugate the matrix but must preserve its spectrum/trace.
