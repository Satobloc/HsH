## Work completed — toroidal inverse benchmark
The manuscript defines the standard torus embedding

\[
X(\phi,\psi)=((R+a\cos\psi)\cos\phi,(R+a\cos\psi)\sin\phi,a\sin\psi)
\]

and says a one-parameter helical history can be encoded as `s -> X(phi(s),psi(s))`, with winding slope `q=dpsi/dphi`. It separately says the Whirligig is a special lower-dimensional compression/projection whose exact status requires explicit transformation.

For an ordinary ring torus with declared `R>a>0`, the full embedded torus coordinate is invertible to the two phases modulo `2pi`:

\[
\phi=\operatorname{atan2}(Y,X),
\]
\[
\psi=\operatorname{atan2}\!\left(Z,\sqrt{X^2+Y^2}-R\right).
\]

Reason: `sqrt(X^2+Y^2)=R+a cos psi > 0`, so the major-angle branch is well-defined modulo `2pi`, and `(sqrt(X^2+Y^2)-R,Z)=a(cos psi,sin psi)` recovers the minor phase modulo `2pi`.

Therefore, with `R,a` known and the full oriented 3D torus embedding retained, the toroidal map does **not** inherently discard the two periodic phase coordinates. A continuous history also recovers unwrapped phase increments after choosing initial lifts/branch continuity; wherever `dphi/ds != 0`, `q=(dpsi/ds)/(dphi/ds)` follows. Reversing the oriented winding reverses the signed slope under a fixed orientation convention.

This is a useful positive control against Runs 042–044: bare Hagalaz loses independently typed atlas variables unless an embedding supplies them, while the manuscript's *broader toroidal encoding* can preserve the two explicit phase channels by construction.
