## 6. Ground-state persistence and minimal-pair test overlay

The direct source imposes a distinct requirement: an intrinsic oscillation must remain present in the ground state. Excited-state resonances or harmonics cannot substitute for that baseline. Zitterbewegung's literal interpretation as internal motion is separate, and Compton/ZB scales are explicitly excluded as shortcuts for assigning filament size.

A usable test therefore needs:

1. A source-defined intrinsic oscillation parameter or invariant, with its parameterization tied to proper time or another physically calibrated clock.
2. A detector-level readout that remains defined in the ground state.
3. A separate account of excitation-dependent resonances/harmonics.
4. A shared geometry/readout map that does not acquire a new fitted frequency for each state.
5. A standard QED/nuclear comparator using the same calibration and measurement domain.
6. An independent holdout and a falsification threshold derived from the actual measurement covariance and detection sensitivity.

The direct minimal-pair method adds a second constraint: start with established physics, map into Minkowski geometry without adding primitives, then compare two highly constrained systems that share the known parameters and differ in one predeclared factor such as charge or flavor. Calibrate the shared map on one system, freeze it, and predict the second. Do not retune the geometry independently for each member.

If the H(s)H readout factors through the same standard-physics state and yields no new observable contrast, the result is a representational change, not a new prediction. If a contrast exists, it must be frozen before the holdout. No numerical threshold can be set until the observable and its covariance are defined.

This is a proposed overlay on the existing model-selection and measurement-domain gates, not a new general schema. No specific minimal pair is selected.
