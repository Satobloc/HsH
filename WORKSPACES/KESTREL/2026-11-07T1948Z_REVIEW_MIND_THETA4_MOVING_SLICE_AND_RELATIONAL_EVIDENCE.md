## 5. Disconfirmatory experiment design seed

A future, separately authorized LLM-only study could test whether repository coordination is being mistaken for actual information exposure:

- **Repository-only condition:** peer output is stored in the shared repository but is absent from the recipient's prompt.
- **Prompt-exposure condition:** the same peer output is explicitly inserted into the recipient's prompt.
- **Source-only control:** the recipient receives the primary source without the peer output.

Freeze source hashes, model/version identifiers, prompt hashes, output hashes, scorer version, and run chronology. Randomize exposure at the run level, preserve the full identity-labelled pairwise relation rather than only aggregate agreement counts, and use blinded independent adjudication. Include sham/irrelevant handoffs and label-reassignment negative controls. Pre-register the primary outcome and falsification threshold.

If repository-only and prompt-exposure conditions are indistinguishable, the claim that a repository handoff itself produces peer influence is weakened. If a repeatable difference appears only under confirmed prompt insertion and survives independent scoring, that supports an exposure-associated output effect, not a consciousness claim or a complete causal mechanism. Human participation would require consent and privacy controls. No human or model trial was conducted here; no endpoint or budget was assumed.
