### Local exact-phase consequence

For constant \`alpha_*\`, a smooth scalar phase \`theta\`, and a torsion-free connection:

\[
F_{\mu\nu}
=\alpha_*\,\nabla_{[\mu}\nabla_{\nu]}\theta
=0
\]

on each smooth patch. Thus the local Blockwave term \`F_{mu nu}(theta) J^{mu nu}\` vanishes on such patches. Nontrivial global winding or holonomy is not the same thing as nonzero local curvature. A defect, singularity, nontrivial bundle/patching, or a genuinely non-exact connection would need to be specified to obtain a nonzero local \`F\`.

### Holonomy normalization

If a compact phase has winding number \`n\`, then \`oint d theta = 2 pi n\`. With \`A = alpha_* d theta\`:

\[
\oint A = 2\pi\,\alpha_* n
\]

The source's assertion that this is automatically in \`2 pi Z\` requires a normalization condition on \`alpha_*\` (or a redefinition of the connection/charge convention). Compactness alone does not fix that coefficient. No such normalization is supplied in the attachment.

### Local-kernel cross-term condition

If \`J = sum_i J_i\` and \`M\` is a pointwise local symmetric kernel, the quadratic term expands into self-terms and pairwise cross-terms. For disjoint supports, the direct local cross-terms vanish. This is a conditional algebraic observation, not a physical no-force theorem and not Lean-compiled. A shared dynamical \`u\` or \`theta\` medium could mediate indirectly, but the attachment does not define the Kelvin state, boundary conditions, constitutive response, or source-to-medium-to-filament readout.
