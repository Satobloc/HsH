## Construction
Take a core coordinate x(t) with
\[
\ddot x+\omega_c^2 x+\int_0^\infty \Gamma(u)\dot x(t-u)\,du=0.
\]
Use the minimal causal exponential kernel
\[
\Gamma(u)=\Theta(u)\frac{A(a)}{\tau}e^{-u/\tau}.
\]
With Fourier convention \(e^{-i\omega t}\),
\[
\Gamma(\omega)=\frac{A(a)}{1-i\omega\tau},
\]
and the induced self-energy is
\[
\Sigma(\omega)=-i\omega\Gamma(\omega)
=\frac{A(a)\omega^2\tau}{1+\omega^2\tau^2}
-i\frac{A(a)\omega}{1+\omega^2\tau^2}.
\]
Hence causality ties reactive shift and damping:
\[
\frac{\Re\Sigma}{-\Im\Sigma}=\omega\tau.
\]
A constant-damping fit throws away the real partner and can therefore misassign a medium effect to core stiffness.

If \(A(a)\propto a^q\) and the core frequency scales \(\omega\propto a^{-1}\), then
\[
|\Sigma|=\frac{A(a)\omega}{\sqrt{1+\omega^2\tau^2}}
\]
has apparent radius slope
\[
\boxed{\zeta_{\rm raw}=q-\frac{1}{1+(\omega\tau)^2}}.
\]
Thus the same physical coupling crosses from \(q-1\) in the Markov regime \(\omega\tau\ll1\) to \(q\) in the memory-dominated regime \(\omega\tau\gg1\). A one-power drift in a fitted support exponent can be generated by unresolved memory alone.

## Discriminator
Measure both pole shift and linewidth over radius/frequency. The one-pole kernel requires
\[
\tau_{\rm inferred}=\frac{\Re\Sigma}{\omega(-\Im\Sigma)}
\]
to be constant if the medium relaxation time is fixed. Correcting by the measured transfer function must collapse the apparent radius exponent back to one constant \(q\).

## Failure conditions
Reject this minimal kernel if inferred tau depends strongly on frequency after uncertainties, if the shift/damping relation fails, if multiple relaxation poles are required, if the kernel is non-passive, or if the same response cannot fit both real and imaginary pole motion.
