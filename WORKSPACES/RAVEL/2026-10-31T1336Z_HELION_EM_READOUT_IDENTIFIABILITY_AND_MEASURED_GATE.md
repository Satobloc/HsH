## 4. New measurement-lineage correction

The prior Ravel contract treated the published helion charge radius and bare-nucleus magnetic moment as measured anchors. That is useful shorthand, but too coarse for a serious geometry-to-observable test.

### CREMA charge radius

CREMA Collaboration, *Science* 388 (2025), DOI [10.1126/science.adj2610](https://doi.org/10.1126/science.adj2610), reports

[
r_h=1.97007(94)\;\mathrm{fm}.
]

This value is extracted by comparing three measured muonic-helium transition energies with atomic/nuclear theory. It is an experimentally constrained rms charge radius, not a directly observed worldtube boundary or finite-core support radius.

Using the published central value and uncertainty:

[
r_h^2=3.8811758049\;\mathrm{fm}^2,
\qquad
\delta(r_h^2)_{\rm linear}=2r_h\,\delta r_h
=0.0037037316\;\mathrm{fm}^2.
]

The uncertainty propagation is first-order. The square is the charge-distribution second moment under the standard rms-radius definition; it is not the square of a tube-envelope radius.

### Schneider magnetic moment

Schneider et al., *Nature* 606, 878–883 (2022), DOI [10.1038/s41586-022-04761-7](https://doi.org/10.1038/s41586-022-04761-7), directly measured the bound-ion nuclear factor

[
g'_I=-4.2550996069(30)_{\rm stat}(17)_{\rm sys}.
]

The bare-nucleus value

[
g_I=-4.2552506997(30)_{\rm stat}(17)_{\rm sys}(1)_{\rm theo}
]

is derived using the calculated diamagnetic shielding

[
\sigma_{^3\mathrm{He}^+}=0.00003550738(3).
]

For nuclear spin (I=1/2), the reported bare-nucleus central value gives

[
\mu_h/\mu_N=I g_I=-2.12762534985.
]

Thus the bare-nucleus magnetic moment is not a raw, uncorrected measurement: it is a theory-corrected inference from the directly measured bound-ion factor. The three quoted uncertainty components remain separate. If treated as independent for quadrature after division by two, the components in \(\mu_N\) are (1.5\times10^{-9}), (8.5\times10^{-10}), and (5\times10^{-11}); the quadrature standard uncertainty is (1.724818831\times10^{-9}\,\mu_N). No covariance matrix was supplied in the retrieved source, so this combination is conditional on independence.

### Historical SAT value: precision/rounding ambiguity

The historical March 2026 paper value is (-2.127\,\mu_N), with no quoted uncertainty, reproducible derivation, or declared rounding convention. Against the Schneider central value:

[
\Delta\mu=+0.00062534985\,\mu_N,
\qquad
\frac{|\Delta\mu|}{|\mu_h|}\times100
=0.0293919157\%.
]

This percentage is not a prediction score. The convention ambiguity is material:

- nearest rounding to (0.001\,\mu_N) gives the interval ([-2.1275,-2.1265]); the measured central value is below that interval by (0.00012534985\,\mu_N);
- truncation toward zero gives ([-2.128,-2.127)); the measured central value lies inside it.

Because the historical value declares neither convention nor uncertainty, no significance or accuracy score is justified. Moreover, the 2022 magnetic-moment result and 2025 radius result predate the March 2026 paper. Without an independently timestamped derivation predating those observations, (-2.127) is not a blind prediction.

## 5. The key identifiability improvement

A Hodge dual is a type conversion, not a magnetic-moment calculation.

Under a specified induced Lorentzian metric/orientation (g_L), a standard reference Maxwell source hierarchy can be written (with convention-dependent signs/units fixed explicitly):

[
F=dA,
\qquad
dF=0,
\qquad
d(*_{g_L}F)=\mu_0\,\mathcal J^{(3)}_{\rm em},
\qquad
\mathcal J^{(3)}_{\rm em}=*_{g_L}j^\flat_{\rm em},
\qquad
d\mathcal J^{(3)}_{\rm em}=0.
]

This is a standard reference form, **not a correction to Nathan's SAT equations** and not a recovered H(s)H law. The three-form is the source current; its Hodge dual is the current one-form/vector. The magnetic dipole moment is a further spatial readout of the current distribution (for a localized stationary current, conventionally (\boldsymbol\mu=\tfrac12\int\mathbf r\times\mathbf j\,d^3x)), not the Hodge dual itself.

For a spin-1/2 target, the standard elastic electromagnetic matrix element has two independent scalar form factors (F_1(Q^2)) and (F_2(Q^2)), equivalently Sachs (G_E(Q^2)) and (G_M(Q^2)). In the usual convention,

[
G_E(Q^2)=G_E(0)\left[1-\frac16 r_E^2 Q^2+O(Q^4)\right].
]

A single rms charge radius therefore constrains only the low-(Q^2) electric slope. It does not determine the full electric profile, the magnetic form factor, or a finite-core support radius.

**New discriminator:** saying “one conserved current generates both (G_E) and (G_M)” is not yet predictive. The standard spin-1/2 current permits two independent form-factor functions. H(s)H gains a discriminating test only if both functions are derived from the same frozen finite-core geometry and a bounded shared parameter set. If (F_1), (F_2), or a magnetic profile can be independently retuned after the electric calibration, the “one-current” claim has hidden functional freedom and no useful held-out prediction.
