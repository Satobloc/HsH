## 5. Mathematical separations that prevent false equivalence

### 5.1 Torus versus Klein: Euler characteristic is insufficient

For closed surfaces:
[
\chi(T^2)=0,\qquad \chi(K^2)=0.
]
They are nevertheless not homeomorphic: (T^2) is orientable and (K^2) is nonorientable. Their first homology groups differ:
[
H_1(T^2;\mathbb Z)\cong\mathbb Z^2,\qquad
H_1(K^2;\mathbb Z)\cong\mathbb Z\oplus\mathbb Z/2.
]

Therefore an Euler-characteristic or “number of holes” calculation alone cannot select the Klein branch. The orientation-reversing cycle/monodromy is the discriminating structure.

### 5.2 Mapping-torus formulation: the cleanest candidate bridge

A mapping torus is:
[
M_Q=(F\times[0,L])/((x,L)\sim(Qx,0)).
]

For the 2D toy:
- (F=S^1), (Q=\mathrm{id}) gives a torus.
- (F=S^1), (Q) a reflection gives a Klein bottle.

For a possible 4D analogue:
- (F=S^3), (Q\in O(4)).
- An orientation-preserving (Q\in SO(4)) gives an orientable mapping torus.
- An orientation-reversing (Q) gives a nonorientable total space.

This is a precise mathematical way to encode the archive's “twist” as monodromy rather than an informal deformation. It is **not yet the physical model**: the direct sources do not specify (F), (Q), (L), or the embedding of (C_{\rm in}), (C_{\rm out}), and the Kerr CSC.

### 5.3 Topology change versus expansion versus metric deformation

Keep these as separate operations:

1. **Expansion:** changes metric lengths/scale; by itself it does not change homeomorphism type.
2. **Orientability change:** changes the gluing/monodromy from orientation-preserving to orientation-reversing.
3. **Handle addition:** changes orientable genus.
4. **Crosscap insertion/orientation-reversing surgery:** changes nonorientable type.
5. **Finite-core deformation:** changes local material shape/strain and may trigger reconnection, but needs a constitutive rule.

The user's “twist + expansion + reconnection limit” could contain these operations, but the assistant's connected-sum analogy does not identify which surgery is intended. The torus-to-Klein transition needs an orientation-reversing gluing or equivalent crosscap operation; adding an ordinary orientable handle is not enough.

### 5.4 Antimatter requires a fiber action

The Klein relation
[
aba^{-1}=b^{-1}
]
could act on particle internal states through a representation (\rho). A candidate would be:
[
\rho(a)=C,\qquad \rho(b)=W,qquad CWC^{-1}=W^{-1},
]
where (C) is a proposed charge-conjugation action and (W) a winding/phase operator.

This is a formal target, not a derivation. A nonorientable base does not automatically implement charge conjugation, preserve spin-statistics, or supply a charged spinor bundle. A Pin/Pin\(^c\)-type structure or an explicitly equivalent transition law is required.

### 5.5 CTCs need a causal structure

The current native HsH convention is positive (++++); that metric alone has no timelike cone. Under the standard GR meaning, “CTC” requires a Lorentzian metric and a time orientation or equivalent causal structure.

The direct-labelled July transcript insists that CTCs are required. Preserve that as a model requirement; do not quietly rename them ordinary spatial loops. But the model must supply the effective Lorentzian/causal map that makes them timelike.

The existing Meridian Lean PR #895 proves a useful conditional obstruction: if a strictly increasing global time function is assigned along a future-directed path, that path cannot close. Thus a CTC-compatible model cannot simultaneously retain that global monotone-time premise along the same curves. It needs a different global time structure, a multivalued/periodic coordinate, or a distinct causal construction.

### 5.6 Inner/outer ratio is not yet an equation of state

For an illustrative standard ring torus:
[
\eta=\frac{C_{\rm in}}{C_{\rm out}}
=\frac{R-r}{R+r}.
]
This is a dimensionless embedding ratio. To derive a cosmological equation of state one still needs a physical density functional, for example (\rho_{geom}(\eta,\epsilon,\ldots)), and then (under the standard homogeneous-fluid continuity convention):
[
w_{DE}(a)=-1-\frac13\frac{d\ln\rho_{geom}}{d\ln a}.
]

The archive's qualitative statement that dark energy and elastic modulus set the ratio is a target for such a functional, not the functional itself. No physical calculation or fit was performed here.
