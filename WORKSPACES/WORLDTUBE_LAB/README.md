# H(s)H Worldtube Lab

Live construction workspace for Nathan + Ravel + Janus.

## Purpose

This workspace is for bounded forward-construction work on particle/worldtube geometry. Slack is the live bench; this directory is the durable state. It is not a source-authority layer by itself.

## Default work sequence

1. Native standard formulation / measurement.
2. All-purpose normalization audit (`w = ct` plus declared invertible maps).
3. Residual structure and scale ledger.
4. Minimal idealized worldtube geometry.
5. Readout / slice map.
6. Independent collision test or holdout.
7. Freeze packet.
8. Only then, where useful, formal audit, archive recovery, and reconciliation.

## Current scientific front

Standard filament / Kerr-ER core -> genuine near-core deformable structure -> persistent coil -> finite-timesheet intersection/readout -> measurable particle-scale consequence.

Current first target: persistent-coil triangulation from genuinely independent observables, initially e/mu/tau unless a stronger minimal system presents itself.

## Working assumptions under active attack

- The scale `a = hbar/(2mc)` is assigned to the standard-filament Kerr/ER core rather than to a higher-order coil or readout scale.
- Persistent coiling is the correct geometric carrier of rest-mass behavior in the model.
- A suitable genuine near-core structure exists that can support the coupled force deformation represented on the filament side.

These are not promoted facts. Each should have an internal redundancy check and an external collision test.

## Representation discipline

Keep distinct:

1. reduced Minkowski/worldworm representation;
2. full 4D worldtube/bulk representation;
3. actual 3D or finite-thickness timesheet intersection/readout.

A structure appearing in one representation is not automatically a primitive of another.

## Geometry discipline

Simplified and idealized geometry is expected during metric discovery. Exactness is development-phase dependent, not role-owned. Solver work should recover the corresponding simplified geometry in the appropriate limit.

## Promotion discipline

Nothing generated by unattended or external agents promotes itself. Freeze first; inspect dependencies; then reconcile. Archive recovery may be deliberately withheld until after freeze when semi-blind convergence has evidentiary value.

## Quality target

Evaluate work against multiple bars: competent working physics, top-tier contemporary work, historically strong theoretical construction, and the stricter H(s)H internal bar of dependency purity, reproducibility, independent constraint, adversarial survival, representational consistency, and explicit failure conditions.
