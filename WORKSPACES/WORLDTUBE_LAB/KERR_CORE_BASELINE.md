## 1. Working assignment

For the electron-like reference case, use the Kerr spin parameter

\[
a = \frac{J}{mc}
\]

with

\[
J = \frac{\hbar}{2}
\]

so that

\[
a_e = \frac{\hbar}{2m_e c}.
\]

Current H(s)H working assignment: this scale is provisionally identified with the idealized standard-filament Kerr/ER core transverse scale, not with the persistent-coil radius.

This assignment remains an active assumption to attack.

## 2. Electron-reference numerical scale

Using the electron mass,

\[
a_0 \approx 1.9308\times 10^{-13}\ \mathrm{m}.
\]

The corresponding diameter across the ring scale is

\[
D_0 = 2a_0 = \frac{\hbar}{m_e c}
\approx 3.8616\times 10^{-13}\ \mathrm{m}.
\]

This is the current idealized standard-filament core diameter used in the Worldtube Lab baseline.

## 3. Ring-scale circumference and coordinate mouth area

Circumference:

\[
C_0 = 2\pi a_0
\approx 1.2132\times 10^{-12}\ \mathrm{m}.
\]

Flat-coordinate one-face mouth area:

\[
A_0 = \pi a_0^2
\approx 1.171\times 10^{-25}\ \mathrm{m}^2.
\]

If a two-face coordinate footprint is useful for bookkeeping,

\[
2A_0 \approx 2.342\times 10^{-25}\ \mathrm{m}^2.
\]

Caution: these are coordinate-geometric footprint measures, not automatically invariant proper Kerr areas.

## 4. Basic Kerr cross-sectional geometry

Using the standard Kerr-Schild/Carter-style spatial coordinates,

\[
x+iy=(r+ia)e^{i\phi}\sin\theta,
\qquad
z=r\cos\theta,
\]

constant-\(r\) surfaces satisfy

\[
\frac{x^2+y^2}{r^2+a^2}
+
\frac{z^2}{r^2}
=1,
\]

so they form oblate spheroids.

Define

\[
q=\frac{r}{a_0}.
\]

Then the semiaxes are

\[
R_{\rm eq}=a_0\sqrt{1+q^2},
\qquad
R_{\rm pol}=a_0|q|,
\]

and the diameters are

\[
D_{\rm eq}=D_0\sqrt{1+q^2},
\qquad
D_{\rm pol}=D_0|q|.
\]

Aspect ratio:

\[
\frac{D_{\rm eq}}{D_{\rm pol}}
=
\frac{\sqrt{1+q^2}}{|q|}.
\]

Near the mouth the surfaces are strongly oblate and become progressively rounder outward.

## 5. The r = 0 structure

At \(r=0\), the constant-\(r\) family degenerates to the equatorial disk

\[
z=0,
\qquad
x^2+y^2\le a^2,
\]

whose boundary is the Kerr ring.

Working picture for the current rebuild:

Kerr ring/core -> ER neck/mouth -> outward near-core layered structure -> later persistent coiling of the extended filament/worldtube.

Do not identify the bare Kerr ring itself with the persistent coil.

## 6. Circuit-scale identity already noted

If a closed ring/shell mode of circumference \(C_0\) is provisionally assumed to propagate at \(c\), then the one-circuit time is

\[
T_1=\frac{C_0}{c}
\approx 4.0467\times10^{-21}\ \mathrm{s},
\]

with

\[
\omega_1=\frac{c}{a_0}
=
\frac{2m_ec^2}{\hbar}.
\]

That is exactly the usual Zitterbewegung angular-frequency expression once \(a_0=\hbar/(2m_ec)\) is assumed.

Two circuits give

\[
2T_1=\frac{h}{m_ec^2},
\]

the electron Compton period.

Interpretive caution: these numerical identities are algebraically forced once the Kerr reference scale and propagation speed \(c\) are chosen. Their value is as a convergence of geometric bookkeeping routes, not as an independent prediction.

## 8. Important caution: ordinary ergosphere

Do not casually use the ordinary Kerr ergosphere as the required near-core shell in the electron-like regime. The electron-like Kerr/Kerr-Newman parameters are extremely over-extreme compared with ordinary black-hole parameter ranges, so the standard subextremal horizon/ergosphere picture is not the appropriate default source of shell thickness or geometry.

The near-core carrier must therefore be established from the actual Kerr/ER/Kerr-Newman structure relevant to the regime, not imported by analogy.
