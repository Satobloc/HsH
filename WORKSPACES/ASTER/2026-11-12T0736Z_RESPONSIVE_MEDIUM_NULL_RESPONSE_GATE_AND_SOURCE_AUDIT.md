## 2. Substantive result: a response-null axis

The direct sources distinguish three questions:

1. **Carrier role:** where perturbations may be supported or propagated (worldtube, timesheet, responsive medium).
2. **Representation status:** whether the medium replaces the timesheet, is an elaboration of it, or is retained as an independent third primitive only if evidence and prior geometry require it.
3. **Response activity:** whether the medium contributes nonzero response in a declared regime or approaches a null/impotent limit.

The new addition is the third axis. A medium may be retained as a working model slot yet have zero observable response on a specified domain; it may also have nonzero response that remains representable as timesheet flexure. Neither case automatically requires an independent third state-bearing sector.

## 4. Conditional test contract

Before any physical calculation, an actual measured system and dataset must be identified. Missing source-defined objects are: medium state space M; response map R_M with domain, units, boundary conditions and coupling to an observable; baseline worldtube/timesheet readout; and an explicit medium-to-timesheet representation map.

1. **Null-response:** define the regime where R_M is null and show through an explicit reduction map that the augmented readout reduces to the declared worldtube/timesheet baseline. This is a dynamical/readout reduction, not silent deletion of a variable.
2. **Absorption:** provide a map into an extended timesheet description and show relevant dynamics and readout commute. Static fit or naming similarity is insufficient.
3. **Independent sector:** retain a separate medium only if it has independently specifiable state/evolution or initial/boundary data and a calibrated observable distinction that cannot be reproduced by the allowed W/T representation under shared parameters.
4. **Holdout:** freeze shared parameters and nuisance treatment on calibration data, then test on independent acquisition blocks or conditions. If a medium-sensitive condition cannot be varied independently of W/T geometry, classify NOT_IDENTIFIABLE.
5. **Falsification threshold:** derive from actual instrument covariance and independent-unit structure. No numeric threshold without a real system and data.

This is an additive response-null branch to the existing primitive-economy decision layer in #1486 and model-selection safeguards in #1488, not a replacement.
