[

## 6. New conditional Lorentzian causal-admissibility result

Assume, explicitly and only for this check:

- natural units (c=1);
- Minkowski metric (eta=\mathrm{diag}(-1,+1,+1,+1));
- the displayed coordinate parameterization is used as written.

Then:

[
v^\mu(\lambda)=
\left(
1,
A_xk_x\cos(k_x\lambda+\phi_x),
A_yk_y\cos(k_y\lambda+\phi_y),
A_zk_z\cos(k_z\lambda+\phi_z)
\right).
]

The Minkowski norm is:

[
\eta_{\mu\nu}v^\mu v^\nu
=
-1+
\sum_i A_i^2k_i^2\cos^2(k_i\lambda+\phi_i).
]

Thus the curve is timelike at a given (lambda) exactly when:

[
\boxed{
\sum_i A_i^2k_i^2\cos^2(k_i\lambda+\phi_i)<1
}.
]

For the entire curve, this condition must hold for every (lambda). A simple sufficient, phase-independent bound is:

[
\sum_i(A_i k_i)^2<1.
]

No values for (A_i), (k_i), or (phi_i) were invented or fitted. This is a symbolic admissibility condition, not a physical calculation or measured constraint.

Where the timelike inequality holds, proper time can be introduced by:

[
d\tau=
\sqrt{
1-\sum_i A_i^2k_i^2\cos^2(k_i\lambda+\phi_i)
}\,d\lambda.
]

The unit proper-time tangent is then:

[
U^\mu=\frac{d\gamma^\mu}{d\tau}
=
\frac{v^\mu}{
\sqrt{
1-\sum_i A_i^2k_i^2\cos^2(k_i\lambda+\phi_i)
}
},
\qquad
\eta_{\mu\nu}U^\mu U^\nu=-1.
]

This supplies a conditional normalization map from the displayed affine/coordinate-like parameter to proper time.

If (lambda) is intended to be proper time already, then the displayed (v^mu) must satisfy (v^2=-1) identically. With (gamma^0=\lambda) and nonzero spatial oscillations, that is not generally true. The source must therefore declare whether (lambda) is a coordinate-like affine parameter, a proper-time parameter with additional constraints, or another parameter with a specified normalization.
