## 3. Substantive architecture refinement

Treat the model family as:

- H0: established standard comparator;
- H1: minimal/source-admissible SAT/H(s)H core;
- H1+f: one source/representation-justified feature extension.

The pairwise contrasts answer different questions:

1. H0 vs H1: does the tested core make a distinct predictive claim?
2. H1 vs H1+f: does the added feature change the tested prediction, and is that feature necessary within the declared scope?
3. H0 vs H1+f: does the feature-augmented model distinguish from the standard comparator?

A feature result alone cannot establish the core. Conversely, a core contrast does not establish the added feature. A full/ablated comparison remains invalid if removing a source-required feature changes the declared object type; such a comparison is NOT_ABLATABLE / REPRESENTATION_CHANGE.
