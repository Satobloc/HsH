## 4. New source/type boundary clarification

There are three distinct support types in the source set:

1. A one-parameter curve gamma: R -> M^4 is 1D support. Under the static-block reading it is a worldline.
2. A separate one-parameter sweep of a 1D spatial curve produces a 2D worldsheet, if a map F: I x C -> M^4 is actually defined.
3. A 4D worldtube is a full-dimensional region in M^4. It needs an additional thickening/family construction. A tubular neighborhood of a worldline requires a rank-three normal fiber; a tubular neighborhood of a 2D worldsheet requires a rank-two normal fiber. The sources do not select either construction.

The current PR #1594 sweep contract is type 2, not type 3. Its chain identity is:

That identity is a proposed assistant contract, separate from SAT-O and Blockwave source equations. The Lean record assumes the product-boundary law as a premise. It does not prove an embedding, a normal bundle, a finite-core map, a physical current, or a 4D worldtube.

For a 3D timesheet Sigma^3 intersecting a k-dimensional support transversely in M^4, the generic intersection dimension is k + 3 - 4 = k - 1. Thus a 2D worldsheet yields a 1D curve; a 4D region yields a 3D slice. These are different readout objects and cannot be interchanged by analogy.
