## 4. Proposed cognitive-provenance experiment and data model

The factorization criterion suggests a precise, falsifiable measurement architecture.

### Typed provenance graph

Use nodes for:

- human or model run;
- model/backend/version;
- prompt and system/developer context version;
- source corpus and individual source;
- retrieval result/cache;
- memory snapshot;
- tool call and returned artifact;
- evaluator/judge prompt and output;
- revision event;
- human intervention;
- final individual output;
- team/group decision.

Use typed directed edges such as supplied-to, retrieved-from, derived-from, judged-by, revised-by, communicated-to, copied-from and aggregated-into. Record timestamps and stable content identifiers where available.

A candidate source-dependence profile should keep separate axes for source-corpus overlap, prompt/context overlap, retrieval/cache overlap, memory overlap, model family/version, evaluator dependence, orchestration/peer communication, human intervention and time/replication. Do not collapse these into one independence score without an explicit model and weights.

### Fibre test

Let H be a complete event-level history, L=P(H) the archived/logged projection, and D=C4(H) a target property such as the upstream provenance graph or a claim-specific dependency profile.

A deterministic archive-only decoder Dbar exists only if:

    P(H1) = P(H2)  implies  C4(H1) = C4(H2).

If two complete histories produce the same archived record but different dependency structures, the archive cannot determine that structure. The correct status is UNKNOWN / NOT IDENTIFIABLE FROM THIS RECORD, not independent.

This is stronger and more precise than counting different model names or output labels.

### Disconfirming design

1. Pre-register the full trace schema and the exact target property before data collection.
2. Randomize shared-source versus disjoint-source exposure, and shared versus independent evaluator conditions, across actual model runs.
3. Preserve full prompt, source, retrieval, memory, model/version, tool-call, evaluator, communication and revision lineage.
4. Use blinded independent human adjudication for a predeclared ground-truth subset, with consent and privacy protections for any human participants.
5. Construct paired trace conditions whose visible logged outputs are matched while upstream dependency edges differ. Test whether an archive-only classifier can recover the predeclared dependency property. If it must return the same result for observationally identical logs while the target differs, the property is not identifiable from that projection.
6. Measure statistical error independence separately using joint error outcomes against independent ground truth. Provenance separation alone does not establish statistical independence; different model names alone do not establish process independence.
7. For nested groups, preserve individual traces -> interaction graph -> group summary -> human decision as explicit projection/composition maps. Event order, feedback edges and peer communication must not be discarded if the target depends on them. Each stage must satisfy the relevant fibre-constancy condition before a downstream summary can be claimed to preserve that target.
