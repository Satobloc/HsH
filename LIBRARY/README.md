# H(s)H Document Library

A curated reading layer over the historical **SAT Theory Archive 2023–25**. The Archive remains the source record; this library selects standout papers, writings, and passages for cleaner presentation and easier reading.

The distinction is deliberate:

- **Presented readings** are reformatted for legibility, with source wording preserved and editorial context kept visibly separate.
- **Raw development record** links go straight to historical files with little or no cleanup.
- The Library never replaces the Archive source.

## How selections enter the Library

Selections are tracked in [`library_manifest.toml`](library_manifest.toml). A whole document can be marked as a **showcase**, a passage can be marked as an **excerpt** with exact source-line ranges, useful untouched records can be marked as **raw picks**, and promising material can remain a private-facing **candidate** until reviewed.

This lets archive readers tag good material as they encounter it without editing the historical file or interrupting their research. The presentation layer can then be built or refined separately.
